# 列表：即时搜索、按列排序、新筛选、编号搜索、远程下拉、填写提示

各列表的搜索框停手约 300 ms 就搜，回车立刻搜；组会和报销也有搜索框。时间、日期、金额、库存、编号、姓名、年级等列点表头在服务器上排序，翻页顺序连续。设备、试件、耗材、采购、经费、成果、报销、知识库、任务看板多了几种筛选。搜完整编号（如 `PR-2026-0001`）只出那一条。表单里选数据集、采购申请、试件、记录的下拉边输边到服务器搜，不再只有前 100 条。位置、类别、材料、单位、研究方向、出处、标签这些框提示本组用过的写法，新写法照样能存。附件上传中离开页面先问；组会附件显示上传进度。

## Sub-features

- `live-search`：在设备台账的搜索框里输入 `UT`，不按回车，约半秒后列表只剩编号或名称含 UT 的设备；输入中文时拼音没选字前不刷新。
- `sort`：采购申请点表头"合计（元）"，按合计升序；再点一次降序；翻到第 2 页时接着排。耗材的"库存"、"最近到期"，报销的"金额""发生日期"，成员的"姓名""年级"同理。
- `filters`：设备 combobox "类别"、"存放位置"、"保管人"和 checkbox "现在空闲"；试件 combobox "材料"、"存放位置"、"缺陷参数"（导师、管理员）；耗材 combobox "分类"、"存放位置"；采购 combobox "经费来源"、"申请人"（管理员、终审人）；经费 combobox "负责人"；成果 checkbox "有全文"；报销日期范围"发生日期从 / 到"；知识库 combobox "标签"（点表格里的标签也按它筛）；任务看板 combobox "负责人"、"里程碑"。
- `search-boxes`：组会列表有 textbox "搜索标题、纪要、汇报内容、汇报人"；报销有 textbox "搜索编号、说明、报销人"，统计页的合计跟着搜索词变。
- `code-search`：在采购申请搜索框输入 `PR-2026-0001`，只出这一张；学生搜别人的编号什么也搜不到。
- `remote-select`：实验记录编辑页的"关联数据集"、"台账试件"，处理记录的"输入数据集""脚本""结果数据集"，周报的三个关联下拉，报销和设备的"采购申请"，耗材入库的"采购申请（已到货）"，输入编号或名称后列出服务器上的匹配；选中后再搜别的，已选的标签名字不变。
- `suggestions`：设备"存放位置"框聚焦时列出本组用过的位置，输入 `A3` 时出现 `A302`；输入一个新位置照样能保存。
- `upload-guard`：组会详情上传附件时出现进度条；上传中点菜单离开，弹出"离开这一页"。

## How to get to it (user POV)

- 左侧栏各模块的列表页；表单在各列表的"新建""编辑"里。
- 手机上筛选收在"筛选"图标后面，排序只在电脑宽度的表头上。

## Driving it with chrome-devtools MCP

1. `mgr` 新建两台设备：`UT-001`（类别 `探伤仪`，位置 `A302`）、`UT-002`（类别 `探头`，位置 `A302`）。第二台的"存放位置"输入 `A3`，`wait_for` 下拉里的 `A302`。
2. 设备台账：textbox "搜索编号、名称、型号、位置" 用 `fill` 填 `002`，不按回车，`wait_for` 列表只剩 UT-002（`fill` 一次填完，等的是停手后的搜索）。清空后 combobox "类别" 选 `探头`；再点表头"编号"两次，确认顺序翻过来。
3. `s_a` 建两张采购申请（合计不同）并提交。`mgr` 在采购申请点表头"合计（元）"，截图；搜索框填第一张的编号，只剩一行。`s_b` 搜同一个编号，`wait_for` "暂无采购申请"。
4. 报销：`s_a` 登记两笔（说明不同），`adv` 在报销页搜其中一笔的说明，切到"统计"，合计只算这一笔。
5. 组会：`mgr` 建组会，议程汇报人选学生甲、汇报内容 `导波成像`；组会列表搜 `导波`，只剩这一场。上传 `slides.pptx` 时截图进度条。
6. 远程下拉：`s_a` 建 3 个数据集，新建实验记录，"关联数据集"输入第 1 个的编号，选中；再输入第 2 个的名称，选中；两个标签都显示"DS-… 名称"。
7. 证据：截图、快照，`query.sh` 读回设备的类别和位置、采购的合计。

## Gotchas

- 防抖是 300 ms；`wait_for` 要等列表内容变化，不要立刻截图。
- 排序只对写了的列生效；点别的表头没有排序箭头。
- 远程下拉在没输入时列最近的 20 条；要找更早的就输入编号或名称。
- 填写提示只来自本组已有数据；刚启动的实例里没有提示，先建几条。
