# 知识库：设备 SDK、手册、调试经验

本组全员都能看、能新建文档；文档可以关联一台设备，按标题、标签、说明、设备编号和设备名搜索。上传新版本不覆盖旧版本，每一版都能下载并显示 SHA256。图片、PDF、文本和 CSV 可点文件名在站内预览，其他类型可下载。作者和管理员能编辑、上传新版本；只有管理员能删除文档。设备详情页的"资料"一栏列出关联这台设备的文档。外组一律 404。

## Sub-features

- `create`：`s_a` 新建文档，保存后提示"已新建，可以上传文件"，对话框出现"上传文件"。
- `versions`：先后上传两个文件，列表"最新文件"显示第 2 版；对话框"文件版本"里两版都在，各有说明、大小、上传人、时间和 SHA256 前 12 位，与样例文件一致。
- `open-or-download`：PDF 版本在浏览器里打开（`content-disposition: inline`），CSV 版本下载（`attachment`），下载内容的 SHA256 与样例文件一致。
- `search`：按设备编号 `PA-001`、按设备名"相控阵"都能找到；搜"电磁"显示"没有符合条件的文档"。
- `readonly-for-others`：`s_b` 打开文档，所有字段灰掉，没有"上传新版本""保存""删除文档"；接口改标题、传新版本、删除都是 403。
- `delete-managers-only`：作者 `s_a` 删除文档是 403（"仅管理员可操作"）；`mgr` 打开同一文档有 button "删除文档"。
- `equipment-docs`：设备详情页"资料"一栏按分类列出关联文档和最新文件；点文档标题进入知识库，设备筛选已选好，文档对话框直接打开。之后点左侧菜单"知识库"，设备筛选回到"全部设备"。
- `isolation`：`x_mgr` 访问文档和版本文件都是 404，文档列表为空。

## How to get to it (user POV)

- 左侧展开 "知识成果" → menuitem "知识库"。列表页：textbox "搜索标题、标签、说明、设备"（回车生效），combobox "分类"、"设备"，button "新建文档"；每行标题是按钮，"最新文件"列可点支持预览的文件名，其他类型显示下载链接。
- 文档对话框：textbox "*标题"，combobox "*分类"、"关联设备"、"标签"（输入后回车，可多个），textbox "说明"；"文件版本"列表；textbox "本版说明（可不填），如 适配新固件"，首次是 button "上传文件"，已有文件时是 "上传新版本"；底部 "删除文档"（只有管理员）、"取消"、"保存"。
- 设备台账 → 某台设备 → "资料" 一栏，button "在知识库中查看"。

## Driving it with chrome-devtools MCP

前提：

- 刚启动的实例。`mgr` 先在设备台账建一台 `PA-001` / `相控阵超声仪`。
- 样例文件 `quote.pdf`、`wave_002.csv`，SHA256 在 `SHA256SUMS`。
- 证据目录：`backend/var/verify-evidence/<日期>-knowledge/`。

步骤：

- **新建。** `s_a` 点 "新建文档"：标题 `OmniScan SDK 安装包`，分类"设备 SDK"，关联设备 `PA-001 相控阵超声仪`，标签 `驱动`，说明随意，点 "保存"，`wait_for` "已新建，可以上传文件"。
- **两个版本。** 本版说明填 `随设备附带的 4.2 版`，对 "上传文件" 用 `upload_file` 传 `quote.pdf`，`wait_for` "已上传第 1 版"；再填 `适配新固件 5.0` 传 `wave_002.csv`，`wait_for` "已上传第 2 版"。两版的 SHA256 前缀分别是 `d009639f2187`、`e4a3b739b469`。截图。
- **打开方式。** `evaluate_script` 请求两个版本的下载链接：第 1 版 `inline`、第 2 版 `attachment`，内容 SHA256 与样例一致。
- **搜索。** `s_b` 打开知识库，搜 `PA-001`、`相控阵` 都只有这一篇；搜 `电磁` 显示"没有符合条件的文档"。
- **只读。** `s_b` 点标题，对话框里字段全部 disabled，没有上传、保存、删除。截图。`evaluate_script` 对 `/api/docs/<id>/` 发 PATCH、DELETE，对 `/api/docs/<id>/versions/` 传文件：都是 403（这是权限反例，不造状态）。
- **删除权限。** 在 `s_a` 页面对 `/api/docs/<id>/` 发 DELETE：403 "仅管理员可操作"。
- **设备页。** `mgr` 打开 `PA-001` 详情，"资料"里有"设备 SDK / OmniScan SDK 安装包 / wave_002.csv（第 2 版）"。截图。点文档标题，地址是 `/knowledge?equipment=<id>&doc=<id>`，设备筛选为 `PA-001`，对话框打开且有 "删除文档"。
- **外组。** `x_mgr` 请求 `/api/docs/<id>/` 和版本文件都是 404，`/api/docs/` 的 `count` 为 0。
- **第二视角。** query.sh 读 `knowledge.models.Doc` 和 `DocVersion`：版本号 1、2，SHA256 与样例一致，存储名是服务器生成的随机名。

- 在有 TXT、CSV 或 PDF 版本的文档里点文件预览入口；核对预览内容，再用下载入口取回该版本。

## Gotchas

- 搜索框回车或失焦后才生效，只填不回车列表不变。
- "关联设备""标签"是可搜索的下拉框，选项有时不出现在无障碍快照里；用 `evaluate_script` 点可见的 `.el-select-dropdown__item`。
- 新建时要先保存，才能上传文件。
