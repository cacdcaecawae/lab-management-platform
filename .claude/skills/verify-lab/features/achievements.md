# 成果归档：论文、专利、获奖、软著

本组全员都能登记成果，记录作者（按署名顺序，含外单位）、本组成员、出处或编号、日期、状态，论文可以上传全文 PDF。按类型、年份、状态、成员筛选；状态筛选里有"已录用（含已发表）"。"导出 Excel"导出当前筛选的清单，"导出（附全文）"导出清单加全文的压缩包，全文按序号命名。外组 404，导出里也看不到外组的成果。

## Sub-features

- `create`：`s_a` 登记一篇已录用的论文，保存后提示"已保存，可以上传全文"，对话框出现 "上传全文"。
- `fulltext`：上传 PDF 后提示"全文已上传"，对话框里有文件链接、"替换全文"、"删除全文"；列表"全文"列出现 link "PDF"。
- `filter-accepted`：类型"论文"、年份"2026 年"、状态"已录用（含已发表）"：只剩 2026 年已录用和已发表的论文，投稿中的论文、2025 年的论文和专利都不在；两个导出链接带上同样的筛选参数。
- `export-with-files`："导出（附全文）"下载 `成果清单与全文-<日期>.zip`，里面是 `成果清单.xlsx` 和 `全文/001-<标题>.pdf` 等；Excel 的行与页面一致，"全文"列写出对应的文件路径，全文 SHA256 与上传的文件一致。
- `isolation`：`x_mgr` 访问成果和全文都是 404，列表为空，导出的清单里没有任何一行。

## How to get to it (user POV)

- 左侧 menuitem "成果归档"。列表页：textbox "搜索标题、作者、出处"，combobox "类型"、"年份"、"状态"、"成员"，link "导出 Excel"、"导出（附全文）"，button "登记成果"；每行标题是按钮，"全文"列是 link "PDF"。
- 登记对话框：combobox "*类型"、"*状态"、"*日期"，textbox "*标题"、"*作者（按署名顺序，含外单位）"，combobox "本组成员"，textbox "期刊 / 会议"、"DOI / 链接"、"备注"；保存后出现"全文（PDF）"和 button "上传全文"。

## Driving it with chrome-devtools MCP

前提：

- 刚启动的实例。样例文件 `quote.pdf`。
- 证据目录：`backend/var/verify-evidence/<日期>-achievements/`。

步骤：

- **登记。** `s_a` 点 "登记成果"：状态选"已录用"，标题 `基于全聚焦方法的焊缝相控阵超声成像`，作者 `学生甲, 导师甲, 外校合作者`，本组成员选"学生甲"，期刊 `无损检测`，点 "保存"，`wait_for` "已保存，可以上传全文"。
- **全文。** 对 "上传全文" 用 `upload_file` 传 `quote.pdf`，`wait_for` "全文已上传"。
- **对照记录。** 再用同样的表单登记：2026 年已发表的论文（上传一份全文）、2026 年投稿中的论文、2025 年已录用的论文、2026 年已授权的专利。
- **筛选。** 类型"论文"、年份"2026 年"、状态"已录用（含已发表）"，列表只剩两篇。截图。读两个导出链接的 `href`：都带 `type=paper&year=2026&status=accepted%2Cpublished`。
- **导出。** `evaluate_script` 请求"导出（附全文）"的地址，把内容转成 base64 存进证据目录，用 Python 解开：两个全文文件加 `成果清单.xlsx`，表里两行，"全文"列与文件名对应，`002-...pdf` 的 SHA256 与 `quote.pdf` 一致。
- **外组。** `x_mgr` 请求成果和全文 404，`/api/achievements/` 的 `count` 为 0。导出返回 200；要核对内容，照"导出"一步解开：压缩包里只有 `成果清单.xlsx`，表里只有表头。
- **第二视角。** query.sh 读 `achievements.models.Achievement`：类型、状态、日期与页面一致，全文存储名为随机名，原文件名在 `fulltext_name`。

## Gotchas

- 下拉框选项不出现在无障碍快照里；先 `click` 下拉框，再用 `evaluate_script` 点可见的 `.el-select-dropdown__item`。年份选项文字是"2026 年"，不是"2026"。
- 导出文件名里的日期按北京时间。验证机器的时区不是北京时，文件名日期可能与页面上显示的日期差一天，这不是错误。
- 新登记的成果要先保存，才能上传全文。
