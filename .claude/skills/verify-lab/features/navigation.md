# 导航：可收起的侧栏分组、共用的顶栏标签、离开前提醒

左侧菜单按模块分组，有几页的模块可以收起、展开（像飞书），每个模块一个颜色。顶栏是一排所有模块共用的标签（像浏览器、网页邮箱）：一开始没有，打开一页就多一个，在哪个模块都在。编辑到一半要离开时先问一句。

## Sub-features

- `modules`：`mgr` 左侧依次是"工作台""通知"，"项目""科研记录""周报组会""设备耗材""采购经费""知识成果"，"成员"。项目和后面五个有彩色图标（青、蓝、紫、橙、绿、粉），工作台、通知、成员是灰色线条图标。学生展开"采购经费"只有"采购申请""报销与统计"。
- `group-toggle`：收起的组左边是彩色图标；点组名展开，图标位置换成浅色底上的向下箭头，下面缩进列出各页；再点收起。
- `group-follows-page`：清掉 `localStorage` 的 `lab.menu.open` 后打开 `/bookings`，"设备耗材"自动展开；去工作台，它自动收起。自己点开的组去工作台后仍开着，刷新后也开着。
- `tabs-start-empty`：清掉 `sessionStorage` 的 `lab.tabs` 后打开工作台，顶栏没有标签（电脑宽度下没有顶栏）。
- `tabs-shared`：依次点"设备预约""设备台账"、列表里的 PR-014、"科研记录 → 实验记录"：顶栏是"设备预约""设备台账""PR-014 双晶直探头""实验记录"四个标签，前三个是橙色圆点、最后一个蓝色圆点；正在看的是白色、和下面的卡片连在一起。回工作台四个都在，都不是白色。
- `tab-close`：在"实验记录"点 button "关闭 实验记录"，跳到它左边的"PR-014 双晶直探头"（右边没有了）；关掉中间的，正在看的不变。
- `tabs-menu`：点标签条最右边的 button "全部标签"（▾），下拉里依次是各个标签（当前的加粗、前面有颜色圆点）和"关闭其他标签""关闭全部标签"。点一个标签名跳过去；"关闭其他标签"只留当前页；在编辑中的组会里改了标题不保存，点当前标签的 ×，弹出"离开这一页"，选"留下"页面和标签都还在。
- `tab-scope`：刷新浏览器后标签还在；退出再登录后没有。最多 10 个，多了最早的消失。
- `new-not-a-tab`："新建组会"页面不是标签；保存后地址变成 `/meetings/<id>`，不弹提醒，出现"<日期> <标题>"标签。删除这个组会后它的标签一起消失。
- `unsaved-guard`：打开"新建实验记录"，"*实验名称"填一句，点任一标签或左侧菜单：弹出"离开这一页"——"有未保存的修改，离开后会丢失。确定离开？"，点"留下"仍在 `/experiments/new`；再点选"离开"就走。什么都没改时直接离开，不问。只读的记录不问。

## How to get to it (user POV)

- 左侧点组名展开 → menuitem（页面）→ 列表里点编号或名称；每打开一页，顶栏多一个标签。

## Driving it with chrome-devtools MCP

- 组名是 `.el-sub-menu__title`，展开的组是 `.el-sub-menu.is-opened`；页面项按无障碍名称（menuitem "设备预约"）点，所在组收起时先点组名。
- 用 `evaluate_script` 读 `nav.tabs .tab` 的文字和 `on` 类，比截图稳定；关闭按钮按无障碍名称"关闭 <标题>"定位。
- 要从干净状态开始，先清掉 `sessionStorage` 的 `lab.tabs` 和 `localStorage` 的 `lab.menu.open`。

## Gotchas

- 记录标签的名字来自详情页卡片头的标题，加载完之前短暂显示通用名（"设备"）。
- 打印标签页（`/labels`）和运维的系统管理页不是标签。
- 正在看的页所在的组被自己收起后，在同一组里换页，它会再自动展开。
- 关浏览器标签页时的提醒是浏览器自己的对话框，文字不能改。
