# 导航：模块菜单、页面标签、打开过的记录、离开前提醒

左侧菜单只列模块；一个模块的几页是顶栏的标签（网页邮箱、浏览器那样：灰色标签，当前的是白色、和下面的卡片连在一起）；打开过的记录跟在后面，是可关闭的标签，在同一个模块里来回切不用先回列表。编辑到一半要离开时先问一句。

## Sub-features

- `modules`：`mgr` 左侧 menuitem 是"工作台""通知""科研记录""设备耗材""采购经费""项目""知识成果""成员"；学生没有"我的审批""经费来源"这两个页面标签。
- `module-remembers`：在"设备耗材"打开"设备预约"，点"采购经费"再点"设备耗材"，回到 `/bookings`；打开过一台设备再离开，回来是那台设备。
- `record-tabs`：在"设备台账"点 PR-014，再回列表点 UT-001：顶栏在"试样与标准件"后面隔一条竖线，多出"PR-014 双晶直探头 ×""UT-001 超声探伤仪 ×"，当前那个是白色、和卡片连在一起，"设备台账"是灰的。去"试样与标准件"再点"PR-014 双晶直探头"，地址是 `/equipment/3`。
- `record-tab-close`：点当前记录标签上的 button "关闭 PR-014 双晶直探头"，回到 `/equipment`，标签消失；另一条还在。
- `record-tab-scope`：去"项目"打开"导波螺栓松动"，顶栏是"项目列表""组会"，后面仍有"PR-014 双晶直探头""UT-001 超声探伤仪"和"导波螺栓松动"；回工作台、去"成员"，三条都在（没有页面标签，只有记录）。在"成员"点"PR-014 双晶直探头"，跳到 `/equipment/3`，页面标签换成设备耗材的四页。最多 8 条，多了最早的消失。刷新浏览器后还在；退出再登录后没有。
- `new-not-a-tab`："新建组会"页面不是标签；保存后地址变成 `/meetings/<id>`，不弹提醒，出现"<日期> <标题> ×"。删除这个组会后它的标签一起消失。
- `unsaved-guard`：打开"新建实验记录"，"*实验名称"填一句，点顶栏"周报"：弹出"离开这一页"——"有未保存的修改，离开后会丢失。确定离开？"，点"留下"仍在 `/experiments/new`；再点"周报"选"离开"，到 `/reports`。什么都没改时直接离开，不问。只读的记录不问。

## How to get to it (user POV)

- 左侧 menuitem → 顶栏 link（页面标签）→ 列表里点编号或名称 → 顶栏多出记录标签。

## Driving it with chrome-devtools MCP

- 用 `evaluate_script` 读 `nav.tabs .tab` 的文字和 `on` 类，比截图稳定；记录标签的关闭按钮按无障碍名称"关闭 <标题>"定位。
- 刷新后标签还在是因为存在 `sessionStorage` 的 `lab.tabs`；要从干净状态开始，先清掉它。

## Gotchas

- 记录标签的名字来自详情页卡片头的标题，加载完之前短暂显示通用名（"设备"）。
- 打印标签页（`/labels`）在主界面外面，不是标签。
- 关浏览器标签页时的提醒是浏览器自己的对话框，文字不能改。
