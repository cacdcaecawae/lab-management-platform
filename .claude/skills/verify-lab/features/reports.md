# 周报：写、提交、需补充、重新提交、已阅

学生每周写一份周报，可以关联自己的实验记录、数据集和处理记录。提交后导师或管理员给出反馈："需补充"必须写明补充什么，学生修改后重新提交；"已阅"后流程结束。每次修改都有历史。

## Sub-features

- `reports-write`：新建周报并保存，出现提示"已保存"。
- `reports-submit`：提交后出现提示"周报已提交"，状态为"已提交"。
- `reports-revision`：导师选"需补充"并填写内容后提交反馈，出现提示"反馈已提交"，学生页面显示"导师要求补充（导师甲）"，状态为"需补充"。
- `reports-resubmit`：学生修改后点"修改后重新提交"，状态回到"已提交"。
- `reports-reviewed`：导师选"已阅"提交反馈，状态为"已阅"。
- `reports-week-fixed`：已保存的周报（草稿、需补充）周一日期框是灰的，不能改；内容照常能改。
- `reports-feedback-guard`：导师在"反馈内容"里写了字没提交，点菜单或"下一份待反馈"会先弹出"离开这一页"。
- `reports-duplicate-week`：从列表写本周周报时会打开已有记录；两个新建页同时保存同一周时，后保存的一页出现"<日期> 这一周的周报已经存在，请在周报列表中打开它继续编辑"。

## How to get to it (user POV)

- 左侧展开 "周报组会" → menuitem "周报" → 学生看到按钮"写本周周报"；导师和管理员没有这个按钮。
- 周报列表里点进某一份周报；导师在周报页底部的反馈表单里给结论。

## Driving it with chrome-devtools MCP

前提：

- 刚启动的实例。`s_a` 本周还没有周报。
- 证据目录：`backend/var/verify-evidence/<日期>-reports/`。

步骤：

- **写周报。** 以 `s_a` 登录，在左侧展开 "周报组会"、点 menuitem "周报"，点 button "写本周周报"。"周一日期"默认为本周一，保持不变。在"本周目标""完成工作""主要发现与证据""下周计划"四个输入框分别填一句话。点 button "保存草稿"，用 `wait_for` 等 "已保存"。
- **提交。** 点 button "提交"，用 `wait_for` 等 "周报已提交"。状态标签为"已提交"。
- **需补充。** 新开 `isolatedContext` 为 `adv` 的页面，用 `adv` 登录，从"周报"列表进入学生甲的这份周报。在反馈表单的"结论"里点 radio "需补充"，在占位为"写明需要补充什么（必填）"的"反馈内容"框填 `补充导波幅值的重复性数据`，点 button "提交反馈"，用 `wait_for` 等 "反馈已提交"。
- **重新提交。** 回到 `s_a` 页面刷新，看到 alert "导师要求补充（导师甲）"，状态"需补充"。修改"完成工作"，点 button "修改后重新提交"，用 `wait_for` 等 "周报已提交"。
- **已阅。** 在导师页面刷新，"结论"选 radio "已阅"，点 "提交反馈"。状态变为"已阅"。截图存证。
- **第二视角。** 运行 `bash .claude/skills/verify-lab/scripts/query.sh 'from reports.models import WeeklyReport; r = WeeklyReport.objects.get(); print(r.status, list(r.feedback.values_list("verdict", "content")), r.history.count())'`，状态为 `reviewed`，有一条 `needs_revision` 和一条 `reviewed` 反馈，历史条数大于 1。
- **同周重复。** `s_a` 返回列表，再点 "写本周周报"，核对地址和打开的周报与刚保存的一致。

- 学生从周报列表点“写本周周报”，已有本周记录时直接进入编辑。新建时选周一，点“带入上周计划”，核对本周目标来自上一周；上周缺报时目标保持原值。本人草稿可删除。
- 导师进入“未交名单”，让名单请求失败，确认出现“未交名单加载失败”，恢复连接后点“重试”。在“本周汇总”切换周次，核对正文和未交名单，下载“导出汇总 Markdown”。在全部周报按学生和关键词筛选，提交反馈后点“下一份待反馈”。

## Gotchas

- 选"需补充"却不写内容，会出现"选择"需补充"时请写明需要补充的内容"，这是预期的校验。
- 反馈表单只对导师和管理员显示，并且只在周报处于"已提交"时可用。
- "周一日期"是必填项，快照里的名称带星号："*周一日期"。
