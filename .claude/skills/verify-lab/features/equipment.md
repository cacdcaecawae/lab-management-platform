# 设备：台账、预约、使用登记

管理员在"设备台账"里登记设备。组里每个人都能在"设备预约"的周视图日历上预约设备，先到先得，不审批；两个人约同一设备的重叠时段，只有一个能成功，同时点也一样。使用开始后，预约人登记"正常 / 异常"，可以附一张照片；登记异常后设备转为"待检查"，不能再预约使用，管理员工作台出现提醒。设备详情页能看到最近谁用过、用完是什么状况，以及修改历史。外组的人看不到这些。

## Sub-features

- `equipment-create`：管理员新建设备后进入详情页，状态"可用"。学生和导师没有"新建设备""编辑设备"按钮。
- `booking-select`：在日历空白时段拖选，弹出"新建预约"，设备、开始、结束已经填好；提交后出现"预约成功"，日历上多一块"UT-001 学生甲"。
- `booking-max`：在"新建预约"里把"结束"填成一年以后，点 "预约"，"结束"下面出现"一次预约不能超过 7 天，更长的实验请分段预约"，对话框不关，日历上没有新预约。
- `booking-overlap`：另一个人约重叠时段，提示"该时段已被预约，请换一个时间"，对话框不关。
- `booking-concurrent`：两个人在同一时刻提交同一时段，一个"预约成功"，另一个 409；数据库里只多一条。
- `usage-report`：使用开始后打开自己的预约，能登记"正常 / 异常"；选异常必须写说明，可附照片。登记后显示"使用后状况"和"照片"链接。
- `needs-check`：登记异常后，设备变为"待检查"；日历上方和新建对话框里出现"UT-001 当前为“待检查”，暂不能预约使用"，强行提交提示"设备当前为“待检查”，不能预约"；已有的后续预约保留。
- `manager-workbench`：管理员工作台"需要你处理"里有一行：类型"设备待检查"（红字）、"UT-001 超声探伤仪"，点它进入设备详情；超过 5 台时最后一行"全部 N 条"进入按"待检查"过滤的设备列表。
- `edit-keeps-needs-check`：管理员先打开"编辑设备"，期间学生登记异常；管理员只改存放位置后保存，状态仍是"待检查"，请求里只有改过的字段；学生仍不能预约。什么都不改直接保存，对话框关闭，不发请求。
- `edit-stale-status`：管理员先打开"编辑设备"并选了"维修"，期间学生登记异常；管理员保存时出现警告"设备状态已被改为“待检查”（你打开时是“可用”），请重新打开编辑框确认"，对话框关闭，详情页刷新为"待检查"。
- `equipment-detail`：详情页"最近使用记录"有使用人、时间、异常说明和照片链接；"修改历史"里有"状态：可用 → 待检查"，原因写明谁登记了什么异常。
- `booking-cancel`：本人能取消自己尚未开始的预约（有确认框），取消后日历上消失；别人的预约没有"取消预约"按钮；已开始的预约本人不能取消。
- `workbench-bookings`：学生工作台"接下来"按天列出进行中和将来的预约（"11/23周一"下面"09:00 – 11:00 UT-001 超声探伤仪"），点一条进入日历并弹出该预约的详情。
- `experiment-equipment`：实验记录表单有"台账设备"下拉框和"设备说明"文本框，保存后两者都在。
- `history-names`：修改历史里保管人、台账设备、项目的变化显示名字（成员显示姓名），不是数字。
- `maintenance-booking`：管理员把设备设为"维修"后，预约页和新建对话框提示暂不能预约使用；类型选"维护（校准、维修占用）"后提示消失，提交成功，日历上是一块橙色斜纹的"UT-001 维护"。
- `advisor-readonly`：导师的设备详情页没有"编辑设备"，设备台账没有"新建设备"，工作台没有"设备待检查"。
- `isolation`：外组管理员打开设备地址看到"记录不存在或无权查看"；设备、预约、照片接口都是 404，列表为空。
- `mobile`：390px 宽度下日历默认是日视图；设备列表在日历上面（不显示小月历），页面打开后滚到 08:00 附近，往上滑是设备列表和工具栏。
- `booking-link`：已经在预约页时，再点工作台或通知里 `/bookings?booking=<id>` 的链接，也会弹出那条预约；关掉弹窗后地址去掉 `?booking`，再点同一个链接还会弹出。
- `purchase-link`（第三期）：新增 / 编辑设备的表单有 combobox "采购申请（已到货）"，只列已到货的采购申请；详情页"采购申请"一行显示单号，管理员、导师是链接。步骤见 [procurement.md](./procurement.md) 的"到货关联"。
- `docs-section`（第四期）：详情页"资料"一栏按分类列出知识库里关联这台设备的文档和最新文件，button "在知识库中查看"。步骤见 [knowledge.md](./knowledge.md) 的"设备页"。

## How to get to it (user POV)

- 左侧展开 "设备耗材"：menuitem "设备台账"、"设备预约"。
- 设备台账 → button "新建设备"（仅管理员）；列表里点编号进入详情；详情页右上角 button "修改历史"、"编辑设备"（仅管理员）、"预约"。
- 设备预约：工具栏 button "上一周"、"下一周"（随视图变成"上一月 / 下一月""上一天 / 下一天"）、"今天"，当前日期范围，radio "月" / "周" / "日"，button "新建预约"。右侧栏是小月历（点哪天跳到那天）、checkbox "只看我的"、"全部设备"和每台设备一个 checkbox（前面的色块就是日历上这台设备的颜色，只勾一台时地址带 `?equipment=`）。日历一小时一格，一天 24 小时都在页面上；月视图点日期进入那天。点日历上的预约块打开 dialog "预约详情"。
- 工作台：卡片"需要你处理"里行首类型为"设备待检查"、"待登记使用"（只列最近 14 天内结束的）的行；卡片"接下来"按天分组的预约。

## Driving it with chrome-devtools MCP

前提：

- 刚启动的实例，没有设备和预约，所以第一台设备 id 为 1。
- 证据目录：`backend/var/verify-evidence/<日期>-equipment/`。
- 时间都是浏览器本地时间。下文"明天""后天"按运行当天换算；"现在"用 `evaluate_script` 取 `new Date()` 的本地分钟。

步骤：

- **新建设备。** 用 `mgr` 登录（`isolatedContext` 为 `mgr`），进入"设备台账"，点 button "新建设备"。textbox "*设备编号" 填 `UT-001`，"*名称" 填 `超声探伤仪`，"型号" 填 `CTS-9009`，"存放位置" 填 `A305 实验台`；combobox "保管人" 按 `ArrowDown`、`Enter` 选"学生甲"；点 button "保存"。页面跳到 `/equipment/1`，状态"可用"，"最近使用记录"为"还没有使用记录"。
- **拖选预约。** 用 `s_a` 登录，打开 `/bookings?equipment=1`。时段格子不在无障碍树里，用 `evaluate_script` 在明天那一列 10:00 的格子按下鼠标、移到 11:30 的格子松开：列用 `.fc-timegrid-col[data-date="<明天>"]`，行用 `.fc-timegrid-slot-lane[data-time="10:00:00"]` 和 `"11:00:00"`（一小时一格，拖选按半小时对齐，松开点取 11:00 那格的下半部分），依次派发 `mousedown`（目标取 `elementFromPoint`）、若干 `mousemove`、`mouseup`（后两个派发到 `document`，`buttons: 1`）。出现 dialog "新建预约"，combobox "*开始" 为明天 10:00，"*结束" 为 12:00。combobox "项目" 选"导波螺栓松动"，textbox "用途" 填一句话，点 button "预约"，`wait_for` "预约成功"。
- **重叠被拒。** 用 `s_b` 登录，打开同一地址，日历上能看到"UT-001 学生甲"。点 button "新建预约"，在 combobox "*开始" 用 `fill` 填明天 11:00 后按 `Enter`，"*结束" 填明天 13:00 后按 `Enter`，点 button "预约"。`wait_for` "该时段已被预约"，对话框仍打开。截图。
- **同时提交。** 在 `s_b` 的对话框里把时间改成后天 14:00–16:00；`s_a` 也点 button "新建预约" 填同样的时间。在 `s_a` 页面用 `evaluate_script` 取 `T = 现在 + 8 秒`（取整到秒），用 `setTimeout` 在 T 时刻点击可见对话框里的主按钮"预约"，返回 T；在 `s_b` 页面用同一个 T 做同样的事。之后一边出现"预约成功"，另一边的网络记录（`list_network_requests`）里 `POST /api/bookings/` 为 409，对话框不关。用 query.sh 读 `Booking`，后天 14:00 只有一条。
- **登记异常。** 取浏览器本地"现在"。`s_a` 点 button "新建预约"，开始填现在，结束填稍后的整点，提交。点日历上这块预约，dialog "预约详情" 里有 radio "正常"、"异常"，没有"取消预约"按钮。点 radio "异常"，textbox "说明" 填 `探头线接触不良，A 扫描无回波`，点“拍照 / 选图”，用文件选择器上传 `<上传目录>\photo.png`，点 button "登记"。`wait_for` "已登记异常"；对话框出现"使用后状况 异常"和 link "照片"。打开设备详情，核对“最近使用实拍”中的人名和缩略图；点缩略图可看大图。另选超过 400 KB 的照片，核对压缩期间不能登记、处理完成后可以提交。截图。
- **照片。** 在 `s_b` 页面用 `evaluate_script` 请求"照片"链接的地址，状态 200，`content-type` 为 `image/png`，SHA256 与 `SHA256SUMS` 里 `photo.png` 一致。
- **待检查。** `s_b` 刷新预约页，出现 alert "UT-001 当前为“待检查”，暂不能预约使用"，之前的预约都还在。点 button "新建预约"，对话框里也有这句；直接点 button "预约"，`wait_for` "设备当前为“待检查”，不能预约"。截图后按 `Escape` 关掉。
- **管理员视角。** `mgr` 打开工作台，"需要你处理"里有一行"设备待检查"和 link "UT-001 超声探伤仪"。打开 `/equipment?status=needs_check`，列表里 UT-001 显示"待检查"和"使用中"。进入详情，"最近使用记录"有学生甲、异常说明和 link "照片"。点 button "修改历史"，有"状态：可用 → 待检查"和"原因：学生甲 登记使用异常：…"。按 `Escape`，点 button "编辑设备"，radio "可用"，"备注"填一句，"保存"，状态回到"可用"。
- **编辑不覆盖待检查（F1）。** 换一台"可用"的设备，或先把 UT-001 改回"可用"。`s_a` 约一个从现在开始的时段。`mgr` 在设备详情页点 button "编辑设备"，对话框里 radio "可用" 选中，先不保存。`s_a` 打开这个预约登记"异常"。`mgr` 在还开着的对话框里只改 textbox "存放位置"，点 "保存"：详情页状态为"待检查"、存放位置是新值；`list_network_requests` 里这次 `PATCH /api/equipment/<id>/` 的请求体（`get_network_request`）只有 `location`。`s_a` 新建一个不重叠时段的预约，`wait_for` "设备当前为“待检查”，不能预约"。`mgr` 再点 "编辑设备" 不改任何字段直接点 "保存"，对话框关闭，网络记录里没有新的 PATCH。query.sh 读设备的修改历史，管理员这一条的 `status` 是 `needs_check`。
- **旧表单改状态被拒（R1）。** 先由 `mgr` 把设备改回"可用"。`s_a` 再约一个从现在开始、不重叠的时段。`mgr` 点 button "编辑设备"，点 radio "维修"，先不保存。`s_a` 对这个预约登记"异常"。`mgr` 点 "保存"，`wait_for` "设备状态已被改为"：对话框关闭，详情页状态为"待检查"。这次 PATCH 的请求体有 `status: "repair"` 和 `status_seen: "available"`，响应 409。query.sh 读设备，状态仍是 `needs_check`。
- **取消。** `s_a` 刷新预约页，点明天 10:00 那块，dialog 里有 button "取消预约"；点它，确认框里再点 button "取消预约"，`wait_for` "预约已取消"，这块从日历消失。再点 `s_b` 的后天那块，dialog 里只有 button "关闭"。
- **学生工作台。** `s_a` 打开工作台，卡片"接下来"日期为今天（蓝色日期块"今天"）的那一组里有正在进行的那条；点它进入 `/bookings?booking=<id>`，自动弹出该预约的详情。
- **实验记录。** `s_a` 打开 `/experiments/new`，选项目、填名称，combobox "台账设备" 选 "UT-001 超声探伤仪"，textbox "设备说明" 填 `自带前置放大器 40 dB`，点 button "保存草稿"，`wait_for` "草稿已保存"，两个字段都还在。query.sh 读 `Experiment` 的 `equipment_item` 和 `equipment`。
- **修改历史显示名字。** `mgr` 新建设备时保管人选"学生甲"，再点 "编辑设备" 把保管人改成"学生乙"并保存。点 "修改历史"，有一行"保管人：学生甲 → 学生乙"。
- **维护预约。** `mgr` 点 "编辑设备"，radio "维修"，保存。打开 `/bookings?equipment=1`，出现 alert "UT-001 当前为“维修”，暂不能预约使用"。点 "新建预约"，点 radio "维护（校准、维修占用）"，对话框里的提示消失；开始、结束填明天 09:00–12:00，"用途"填 `送检校准`，点 "预约"，`wait_for` "预约成功"，日历上出现"UT-001 维护"。
- **导师只读。** 用 `adv` 登录，工作台没有"设备待检查"和"库存不足"；打开 `/equipment/1`，只有 button "修改历史"、"预约"，没有 "编辑设备"。
- **外组。** 用 `x_mgr` 登录，打开 `/equipment/1`，`wait_for` "记录不存在或无权查看"，有 button "返回设备台账"。用 `evaluate_script` 请求 `/api/equipment/1/`、`/api/bookings/<id>/`、照片地址，都是 404；`/api/equipment/` 的 `count` 为 0。
- **手机。** 对 `s_b` 页面 `emulate` 视口 `390x844x2,mobile,touch`，重新打开预约页，是日视图：标题是单日日期，表头只有一天；小月历和设备列表排在日历下面。

## Gotchas

- 时段格子、拖选都不在无障碍树里，只能用 `evaluate_script` 派发鼠标事件；拖选只允许从现在之后开始，过去的格子拖不动。
- 日期选择框可以直接 `fill` 文字（格式 `YYYY-MM-DD HH:mm`），之后要按 `Enter` 才生效。开始时间改到结束之后时，结束会自动顺延 2 小时。
- 开始时间允许比现在早 5 分钟以内（填表的时间）；再早会提示"开始时间不能早于当前时间"。
- 使用登记要求预约已经开始，所以"登记异常"这一步必须约一个从现在开始的时段。
- 状态检查在时段冲突之前：设备待检查时，即使时段也重叠，提示的也是"不能预约"。
- "预约成功""预约已取消""已登记异常"等是几秒后消失的浮动提示，要在操作后立刻 `wait_for`。
- 数据库里的时间是 UTC，页面显示浏览器本地时间。

## 使用统计与 Excel（本次待浏览器验证）

1. 用本组管理员打开台账，点「使用统计」，确认默认北京时间当月。
2. 创建跨北京时间月末的使用预约，记录一次异常；按设备、人员、月份核对显示。跨月小时拆分，预约数和异常只在首月计数；无预约设备为零。
3. 导出 Excel 并核对当前显示的日期、分组和数值。导师能看，学生看不到入口且直接访问统计路由回到工作台。
4. 保存页面快照和合成预约/登记的数据库读回；不要提交证据中的个人资料。
5. 成员或项目转出课题组后，历史预约时长、次数和异常数仍应计入匿名行，页面与 Excel 都不显示当前外组标识。

从工作台带 calibration_within=30 进入后，点左侧 menuitem "设备台账"回到完整设备台账应清除校准筛选；场景由导航组件回归覆盖。
