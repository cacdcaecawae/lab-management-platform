# 项目任务看板与里程碑、进展、项目文件

从「项目」列表打开一个项目，再切到「任务」或「里程碑」。项目详情默认仍为「进展」，工作台任务链接直接打开「任务」。进展写错了，记录人、项目负责人、导师、管理员可以改或删；"项目文件"卡片放开题、中期、结题报告等阶段资料，项目成员上传，全组可看。项目列表能按负责人筛、只看有逾期任务的项目。

## Sub-features

- `tasks`：项目成员新建任务，设置自己为负责人；卡片在「待办」，点击「→ 进行中」再点「→ 完成」，各列随之更新，展开「修改历史」看到两次状态变动（"状态：待办 → 进行中"，不是 todo / doing）；改负责人、里程碑后历史里写名字（"负责人：无 → 学生乙""里程碑：无 → <里程碑标题>"），不是编号。过了截止日期的任务写"截止 2026-xx-xx，已逾期"。
- `milestones`：项目负责人新建里程碑；新任务关联后，里程碑显示任务「0 / 1」，任务完成后为「1 / 1」。删除里程碑，任务还在但不再显示关联，历史记录解除关联（"里程碑：<标题> → 无"）。里程碑卡片有灰色细边框。点"任务""里程碑"标签时地址跟着变成 `?tab=tasks` / `?tab=milestones`；页面开着时再点带 `?tab=tasks` 的链接，也会切到任务。
- `read-only`：同组非项目成员能打开看板及里程碑，但没有新建、编辑、移动按钮；外组成员不能打开项目或任务 API。
- `workbench`：本人有未完成指派时出现「我的任务」，打开对应链接进入项目「任务」标签。只看我的、截止日期和逾期提示符合页面记录。
- `board-filters`：「任务」标签有 combobox "负责人"、"里程碑"，选了只剩对应的任务（勾"只看我的"时负责人下拉隐藏）。
- `assets`：项目详情 tab "资产" 分五块：实验与原始数据、数据处理、设备预约、试件借用、耗材出入库，各列最近 10 条，标题后是总数；多于 10 条时"全部 N 条"打开带 `?project=` 的列表（预约是列表视图，耗材是"流水"标签）。某一块读不出时只有那一块显示"加载失败"。
- `member-logs`：项目成员（不是负责人）`s_b` 在「进展」能看到表单并添加进展；不在项目里的学生没有表单，接口 403"仅本项目成员、管理员或导师可以写进展"。
- `log-edit`：`s_b` 写的进展后面有 button "编辑进展"（铅笔）和 "删除"；弹窗 "编辑进展" 改内容后保存，时间线里换成新内容，记录人仍是学生乙。项目负责人 `s_a`、`adv`、`mgr` 也能改删；同一项目里的其他成员看不到这两个按钮，接口 403"仅记录人、项目负责人、管理员或导师可以修改或删除进展"。删除先确认"删除 <日期> 的这条进展？"。
- `project-files`：卡片 "项目文件" 里项目成员有 button "上传附件"（提示"开题、中期、结题报告等阶段资料，任意类型，单个不超过 2 GB"）；传上 PDF 后列出文件名、大小、上传人和时间，点文件名在线预览，"下载"取回原文件。上传人、项目负责人、导师、管理员有 "删除"。不在项目里的同组学生能看、能下载，没有上传；外组接口 404。
- `overdue`：项目列表的工具栏有 combobox "负责人" 和筛选胶囊 "有逾期任务"；有逾期任务的项目在状态一栏多一个红色标签 "N 个任务逾期"（未完成、截止日期已过）。工作台 "组里有 N 个任务已逾期" 打开 `/projects?overdue=1`：只有一个这样的项目时直接到它的「任务」（`?tab=tasks`），有几个时列出它们。直接跳走时顶栏不留"项目列表"标签（它记着 `?overdue=1`，切回去会再跳一次）。

## How to get to it (user POV)

- 从「项目」打开项目，选择 tab「任务」或「里程碑」。
- 项目详情：基本信息下面是卡片 "项目文件"；「进展」时间线每条后面是 "编辑进展"、"删除"（有权限时）。
- 「新建任务」对话框：标题、说明、负责人、截止日期和里程碑；「新建里程碑」对话框：标题、截止日期、「标为完成」。两个对话框右下角都是「取消」「保存」，标题没填时「保存」是灰的。

## Driving it with chrome-devtools MCP

在隔离实例建立合成项目，指定 `s_a` 为负责人，`s_b` 为成员，另建同组非成员。各身份独立登录验证，外组使用 `x_mgr`。为待办设昨日截止，在页面确认日期标红；变更项目成员后确认原指派标为「已不在项目中」，任务仍可被项目负责人移动或改派。证据目录：`backend/var/verify-evidence/<日期>-project-tasks/`。

进展和项目文件：`s_b` 写一条进展再改掉，`s_a` 删掉另一条；`s_b` 对 "上传附件" 用 `upload_file` 传 `quote.pdf`，点文件名预览；同组非成员看得到、没有上传；query.sh 读 `projects.models.ProjectFile`（存储名是随机名）。逾期：给项目建一个截止日期是昨天的待办，`adv` 的工作台出现 "组里有 1 个任务已逾期"，点它进到这个项目的「任务」。

## Gotchas

- 里程碑完成由项目负责人手动标记，不会在最后一项任务完成时自动关闭。
- 测试只读身份时请选已完成首次登录改密的非项目成员。
