# 项目任务看板与里程碑

从「项目」列表打开一个项目，再切到「任务」或「里程碑」。项目详情默认仍为「进展」，工作台任务链接直接打开「任务」。

## Sub-features

- `tasks`：项目成员新建任务，设置自己为负责人；卡片在「待办」，点击「→ 进行中」再点「→ 完成」，各列随之更新，展开「修改历史」看到两次状态变动。
- `milestones`：项目负责人新建里程碑；新任务关联后，里程碑显示任务「0 / 1」，任务完成后为「1 / 1」。删除里程碑，任务还在但不再显示关联，历史记录解除关联。
- `read-only`：同组非项目成员能打开看板及里程碑，但没有新建、编辑、移动按钮；外组成员不能打开项目或任务 API。
- `workbench`：本人有未完成指派时出现「我的任务」，打开对应链接进入项目「任务」标签。只看我的、截止日期和逾期提示符合页面记录。

## How to get to it (user POV)

- 从「项目」打开项目，选择 tab「任务」或「里程碑」。
- 「新建任务」对话框：标题、说明、负责人、截止日期和里程碑；「新建里程碑」对话框：标题、截止日期、「标为完成」。

## Driving it with chrome-devtools MCP

在隔离实例建立合成项目，指定 `s_a` 为负责人，`s_b` 为成员，另建同组非成员。各身份独立登录验证，外组使用 `x_mgr`。为待办设昨日截止，在页面确认日期标红；变更项目成员后确认原指派标为「已不在项目中」，任务仍可被项目负责人移动或改派。证据目录：`backend/var/verify-evidence/<日期>-project-tasks/`。

## Gotchas

- 里程碑完成由项目负责人手动标记，不会在最后一项任务完成时自动关闭。
- 测试只读身份时请选已完成首次登录改密的非项目成员。
