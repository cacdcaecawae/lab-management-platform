# 数据处理：一页闭环，引用原始数据、上传脚本和结果、提交固定版本

一条"数据处理"在一页里写完：引用的原始数据（自己的实验与原始数据，或项目里队友已提交的），处理算法（直接上传脚本文件、写 git 仓库和 commit，或写软件/方法说明，任一即可），参数和选填的运行环境，处理结果（直接上传结果文件和对比曲线图，图片有缩略图、可预览）和结论。提交时固定所引用数据的版本。

## Sub-features

- `runs-missing`：新建后什么都不填就"提交"，"引用的原始数据"下面写"至少引用 1 条原始数据"，"处理算法"下面写"请上传脚本文件、填写 git 仓库和 commit，或写明软件/方法说明"，"处理结果"下面写"请上传结果文件或填写结论"。
- `runs-method-only`：只写"软件/方法说明"（不传脚本、不填 git、不填运行环境），上传一张结果图，可以提交。
- `runs-files`：在"脚本文件"上传 `processing.py`，在"结果文件"上传 `photo.png`，结果表里那一行有缩略图，点"预览"打开图片。
- `runs-pin`：提交后"引用的原始数据"列出实验编号和 `@` 版本码；之后往那条实验追加文件，这里出现"提交后有新增"。
- `runs-cite-teammate`：学生乙在自己的数据处理里能选到学生甲已提交、关联项目的实验（选项后面写"（学生甲）"），选不到学生甲的草稿。
- `runs-cited-returned`：学生甲的那条实验被导师退回后，学生乙提交数据处理时"引用的原始数据"下面写"EX-… 已不能引用（可能已被退回），请移除后再提交"。
- `runs-copy`：已提交的数据处理点"复制为新草稿"，新草稿带着引用和算法，脚本文件还在（和原记录共用），结果文件是空的。

## How to get to it (user POV)

- 左侧展开 "科研记录" → menuitem "数据处理" → 按钮"新建数据处理"。
- 记录页一张卡片：项目、任务名称、引用的原始数据；"处理算法"（脚本文件、git 仓库、软件/方法说明、方法版本、运行环境、处理参数）；"处理结果"（结果文件、结论）。

## Driving it with chrome-devtools MCP

前提：按 `experiments.md` 用 `s_a` 建好一条关联"导波螺栓松动"并已提交的实验（带 `wave_001.csv`）。证据目录：`backend/var/verify-evidence/<日期>-runs/`。

步骤：

- **缺什么就说什么。** 以 `s_a` 登录，展开 "科研记录"、点 menuitem "数据处理"，点 button "新建数据处理"。textbox "*任务名称" 填 `验证-包络提取`，点 button "提交"。三处出现上面 `runs-missing` 的提示。
- **引用、方法、结果。** 在 combobox "*引用的原始数据" 里输入实验编号，`ArrowDown`、`Enter` 选中；textbox "软件/方法说明" 填 `Origin 2024：5 点平滑后取峰值`。对 "处理结果" 里的 button "上传文件" 用 `upload_file` 传 `photo.png`，`wait_for` "已上传 1 个文件"，那一行有缩略图。点 button "提交"，`wait_for` "已提交，记录已锁定"。"引用的原始数据"显示实验编号和 `@` 加 12 位版本码。截图存证。
- **第二视角。** `query.sh 'from research.models import ProcessingRun; r = ProcessingRun.objects.get(); print(r.status, list(r.experiments.values_list("pk", flat=True)), r.data_versions)'`，`data_versions` 里有那条实验原始数据的数据集 id。
- **版本固定。** 回到那条实验追加 `wave_002.csv`，再打开这条数据处理，引用那一行出现"提交后有新增"。
- **队友引用。** 以 `s_b` 登录新建数据处理，在 "*引用的原始数据" 里搜 `验证`，选项里有学生甲已提交的实验，后面写"（学生甲）"；学生甲的草稿不在选项里。选中后写结论 `复现一致`、方法说明 `Excel 求均值`，点 "保存草稿"。
- **被退回后不能提交。** 以 `adv` 退回学生甲那条实验。`s_b` 回到自己的草稿点 "提交"，"引用的原始数据"下面出现"已不能引用（可能已被退回），请移除后再提交"。
- **复制。** `s_a` 在已提交的数据处理上点 "复制为新草稿"，出现"已从 RUN-… 带入配置，请上传结果文件后保存"；点 "保存草稿"后，"脚本文件"里还是原来的文件，"结果文件"是空的。

## Gotchas

- "引用的原始数据"是远程搜索的下拉：先输入文字等选项出现，再用键盘选；选中的项不会出现在快照的选项里。
- 新建页第一次上传脚本或结果时会先保存草稿（任务名称必填）。
- 复制出来的记录和原记录共用一个脚本文件夹：在其中一条追加脚本，另一条也看得到。
