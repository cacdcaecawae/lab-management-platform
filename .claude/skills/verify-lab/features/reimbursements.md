# 报销与统计

每个人登记自己的报销：经费来源、类别、金额、发生日期，可以关联自己的采购申请，上传发票。报销不审批，状态由本人或管理员推进：待提交 → 已交财务 → 已到账；没有发票不能交财务，交财务后不能再改，要改由管理员退回"待提交"。管理员和终审人可以按经费来源、类别、人员、月份统计，导出 Excel；管理员可以手动给财务邮箱发"已交财务、尚未到账"的提醒。报销是个人数据：本人和本组管理员、终审人可见。

## Sub-features

- `create`：点 "登记报销"，保存后对话框不关，标题变为 "报销 RB-2026-0001"，提示"已登记，请上传发票"，下面出现"发票和附件"；没有发票时对话框里的 "交财务" 不可点。
- `need-invoice`：从列表行点 "交财务" → 确定，提示"交财务前请先上传发票"（是服务器给的原因，不是"提交的数据有误"）。
- `submit`：上传发票后 "交财务" 可点（白底，不是第二个蓝色按钮）；在对话框里改了说明不点保存，直接点 "交财务" → 确定，修改也存上了；交财务后表单只读，提示"已交财务的报销不能修改；需要修改请管理员先退回“待提交”。"，附件不能再删，也没有"上传附件"，状态旁显示交财务时间。
- `manager-return`：管理员在列表里对"已交财务"点 "退回" → 确定，状态回到"待提交"；本人没有 "退回" 按钮。
- `paid`：已交财务 → "已到账"；之后这一行只剩 "历史"。
- `history`：修改历史里状态显示为"待提交 / 已交财务 / 已到账"，退回有原因"管理员甲 退回待提交"，时间是本地时间。
- `stats`：管理员、终审人有 tab "统计"：radio "按经费来源"、"按类别"、"按人员"、"按月份"，表格最后一行"合计"由服务器求和。和上面的筛选（状态、类别、月份、经费来源、人员）共用条件。
- `export`：link "导出 Excel" 下载 `.xlsx`，工作表"汇总"和"明细"，汇总的合计与页面一致。
- `remind-finance`：管理员有 button "财务邮箱" 和 "发送财务提醒"；点 "发送财务提醒" 先弹出确认，点 "发送" 才发，发送中按钮转圈不能再点；课题组没填财务邮箱时提示"课题组还没有设置财务邮箱，请先点“财务邮箱”填写"，平台没启用邮件时提示"平台还没有启用邮件，请联系运维在“系统管理 → 邮件”里设置"。导师没有这两个按钮（接口 403）。改财务邮箱的步骤见 [system.md](./system.md) 的 `finance-email`。
- `isolation`：同组其他学生只看到自己的（列表为空），没有"统计" tab；别人的报销和发票 404，统计和导出 403。

## How to get to it (user POV)

- 左侧展开 "采购经费" → menuitem "报销与统计"。
- 工具栏：combobox "状态"、"类别"、"全部月份"（月份选择）、"经费来源"、"人员"（管理员、终审人），button "登记报销"。
- tab "报销记录"：点编号打开对话框；每行操作 "交财务" / "已到账"（本人或管理员）、"退回"（管理员，已交财务时）、"历史"。
- tab "统计"（管理员、终审人）：分组单选、link "导出 Excel"、button "财务邮箱" 和 "发送财务提醒"（管理员）。

## Driving it with chrome-devtools MCP

前提：

- 先走完 [procurement.md](./procurement.md)，有经费来源 `NSFC-001`、`HX-002` 和学生甲已到货的 PR-2026-0001。单独走时，先用 `mgr` 建两条经费来源，关联采购那一步跳过。
- 证据目录：`backend/var/verify-evidence/<日期>-reimbursements/`。

步骤：

- **登记。** `s_a` 进入"报销与统计"，只有 tab "报销记录"，没有"人员"筛选。点 "登记报销"：combobox "*经费来源" 选 `NSFC-001`，类别保持"耗材"，spinbutton "*金额（元）" `144`，combobox "关联采购申请" 选 PR-2026-0001，textbox "说明" `耦合剂 3 瓶`，"保存"，`wait_for` "已登记，请上传发票"。
- **没有发票。** 点 "取消" 关掉对话框，在列表行点 "交财务" → 确定，`wait_for` "交财务前请先上传发票"。
- **发票、交财务。** 点编号 RB-2026-0001，附件类型默认"发票"，对 "上传附件" 用 `upload_file` 传 `quote.pdf`，列表"发票"列变"已上传"。点对话框里的 "交财务" → 确定，`wait_for` "已改为“已交财务”"，表单变灰。截图。
- **第二笔。** 再登记一笔：经费 `HX-002`，类别"差旅"，金额 `820`，combobox "*发生日期" 填 `2026-10-20` 后按 `Enter`，说明 `超声年会差旅`，保存后关掉。
- **管理员退回、到账。** `mgr` 进入"报销与统计"，有"报销人"列和 tab "统计"。对 RB-2026-0001 点 "退回" → 确定，`wait_for` "已改为“待提交”"；再 "交财务"（有发票，直接成功）。
- **统计和提醒。** 点 tab "统计"，默认按类别：差旅 820.00、耗材 144.00、合计 964.00。点 "发送财务提醒"，`wait_for` "课题组还没有设置财务邮箱"。点 radio "按月份"：2026-10 820.00、2026-11 144.00。截图。
- **导出。** `evaluate_script` 用 `fetch` 读 link "导出 Excel" 的地址，转成 base64 存到证据目录，再在本地用 openpyxl 打开：汇总最后一行"合计 2 964"，明细 2 行。
- **到账、历史。** 回到 tab "报销记录"，对 RB-2026-0001 点 "已到账" → 确定，再点 "历史"：依次是创建、交财务、"管理员甲 退回待提交"、交财务、到账。截图。
- **导师、其他学生。** `adv` 打开页面：有 "统计" 和 "导出 Excel"，没有 "发送财务提醒"，行里只有 "历史"。`s_b` 打开页面：只有"报销记录"且为空；`evaluate_script` 读 `/api/reimbursements/1/`、`/api/attachments/<发票 id>/file/` 为 404，`/api/reimbursements/stats/`、`/api/reimbursements/export/` 为 403。
- **数据库。** query.sh 读 `Reimbursement`：RB-2026-0001 `paid`，`submitted_at`、`paid_at` 有值，`purchase` 为 1；RB-2026-0002 `pending`。

- 打开带 PDF 附件的报销单并点文件名，确认弹窗显示对应票据且可下载。

## Gotchas

- 状态推进前都有确认框，点 "确定" 之后才发请求。确认框是页面内的 `.el-message-box`，不是浏览器原生弹窗。
- 验证机的时区如果不是北京时间，页面上的时间（浏览器时区）和导出 Excel 里的"交财务""到账"日期（服务器 `TIME_ZONE = Asia/Shanghai`）可能差一天，这是正常的。
- 手动"发送财务提醒"需要课题组填了财务邮箱，并且运维在"系统管理 → 邮件"里启用了邮件。验证实例刚启动时两样都没有，只能验证提示文字；真实发信未验证。
