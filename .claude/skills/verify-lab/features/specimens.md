# 试样与标准件：台账、盲测缺陷参数、借用

管理员在"试样与标准件"里登记试块、对比试块、试样，每件可以记多个缺陷（类型、尺寸、埋深、位置）。缺陷参数默认只有管理员和导师能看：用于盲测时，学生在页面和接口里都拿不到，管理员打开"对学生公开"后才能看到。组里每个人都能借用"可用"且没借出的试件，借用人或管理员登记归还；同一件同时只能有一条未归还的借用。实验记录可以选"台账试件"。外组看不到。

## Sub-features

- `create`：管理员点 "新建试件"，填编号、名称，点 "添加缺陷" 两次并填尺寸、埋深、位置，保存后跳到详情页 `/specimens/<id>`，"缺陷参数"表格两行，旁边标签"学生看不到"。学生没有"新建试件""编辑试件"按钮。
- `blind-defects`：学生打开详情，"缺陷参数"处只有"缺陷参数未公开（用于盲测），管理员公开后才能看到。"；`fetch('/api/specimens/1/')` 和列表里的 `defects` 都是 `null`，响应里没有缺陷的任何字段值。
- `borrow`：学生点 "借用"，dialog "借用 <编号>" 里选项目、填用途和预计归还日期，点 "借用" 后提示"已登记借用"，状态旁出现"学生甲 借用中"；预计归还日期早于今天时显示"已逾期"，借用记录里该日期后面写"（已逾期）"。按钮变成 "登记归还"。
- `others-cannot`：另一个学生在列表里看到"学生甲 借用中"；详情页没有"借用"和"登记归还"按钮；直接请求 `borrow` 返回 409 `on_loan`，`return` 返回 403。
- `return`：借用人点 "登记归还"，在提示框里填"完好"，点 "确定"，提示"已登记归还"，借用记录多出归还时间和"· 完好"，按钮回到 "借用"。
- `publish`：管理员编辑，打开 switch "缺陷参数对学生公开" 并改一个缺陷的位置，保存后标签变"学生可见"；学生刷新后看到缺陷表格。
- `history`：button "修改历史" 里有"缺陷参数对学生公开：否 → 是"和"原因：修改了缺陷参数"，不出现缺陷的数值。
- `experiment-link`：学生新建实验记录，combobox "台账试件" 选这件试件，"保存草稿"后标签"CSK-IA-01 CSK-IA 标准试块"保留。实验记录里只有编号、名称和状态，没有缺陷参数。
- `stale-return`：管理员打开"登记归还"的提示框不关；学生甲归还、学生乙借走同一件；管理员再点 "确定"，提示"借用记录已变化，请刷新后重新核对"，页面自动刷新为"学生乙 借用中"，学生甲那条的归还说明不变。再点 "登记归还"、"确定"，提示"已登记归还"。2026-11-18 走过（准备数据和学生的操作用 `fetch` 调接口，管理员的操作在页面上点），证据 `2026-11-18-specimens-review/`。
- `filters`（未走过，只有接口测试）：工具栏的"类别""状态"下拉框，checkbox "只看借出的""我借的"。
- `isolation`（只有接口测试）：外组管理员请求详情、借用都是 404，列表为空；编号只在组内唯一。

## How to get to it (user POV)

- 左侧菜单"设备耗材"分组 → menuitem "试样与标准件"。
- 工具栏：textbox "搜索编号、名称、材料、位置"、combobox "类别""状态"、checkbox "只看借出的""我借的"、button "新建试件"（仅管理员）。
- 详情页：button "修改历史"、"编辑试件"（仅管理员）、"借用"或"登记归还"；卡片"缺陷参数""借用记录"。
- 实验记录编辑页：combobox "台账试件"（可多选）。

前提：刚启动的实例，没有试件，第一个试件 id 为 1。证据目录：`backend/var/verify-evidence/<日期>-specimens/`。

- **学生看不到。** 新的 isolatedContext 用 `s_a` 登录，直接打开 `/specimens/1`，`wait_for` "未公开"。`evaluate_script` 读 `/api/specimens/1/` 和 `/api/specimens/` 的 `defects`，都是 `null`。截图。
- **借用。** 点 "借用"，combobox "项目" 用 ArrowDown、Enter 选"导波螺栓松动"，"用途"填一句，combobox "预计归还日期" 用 `fill` 填昨天的日期再按 Enter，点 dialog 里的 "借用"，`wait_for` "已登记借用"。截图。
- **别人借不了。** 用 `s_b` 登录打开列表，`wait_for` "借用中"；打开详情，`evaluate_script` 读 `main` 里的按钮文字（只有"修改历史"），并带 `X-CSRFToken` POST `borrow/`（409 `on_loan`）和携带当前 `loan_id_seen` 的 `return/`（403）。
- **归还。** 回到 `s_a`，点 "登记归还"，提示框里 `fill` "完好"，点 "确定"，`wait_for` "已登记归还"。
- **公开和历史。** `mgr` 刷新详情，点 "编辑试件"，改第 2 个缺陷的位置后保存。再点 "编辑试件"，打开 switch（见 Gotchas），点 "保存"，`wait_for` "学生可见"。点 "修改历史"，`wait_for` "修改了缺陷参数"。截图。`s_a` 刷新详情，缺陷表格出现。
- **实验记录。** `s_a` 打开 `/experiments/new`，选项目、填名称，combobox "台账试件" 用 ArrowDown、Enter 选中，按 Escape 收起，点 "保存草稿"，`wait_for` "EX-"。截图。
- **数据库。** 用 query.sh（加 `PYTHONIOENCODING=utf-8`）读 `Specimen.defects`、`SpecimenLoan`、`Experiment.specimen_items` 和 `Specimen.history` 的 `history_change_reason`。实验记录的编号 `code` 是属性，不能放进 `values_list`。

## Gotchas

- Element Plus 的 switch 和 checkbox 把真正的 input 藏起来了：`click`、`fill` 对 switch "缺陷参数对学生公开" 都会超时。用 `evaluate_script` 点可见的部分：`document.querySelector('.public-switch .el-switch__core').click()`，再读 `.public-switch` 是否有 `is-checked`。列表的两个 checkbox 也是同样的问题，点它们旁边的文字。
- 缺陷的尺寸、埋深是 spinbutton，页面显示两位小数（"2.00"）。
- 预计归还日期允许填过去的日期，"已逾期"按浏览器本地日期判断。

## 归还批次与缺陷校验回归

- 管理员打开 A 的归还弹窗后保留；A 在独立会话归还，B 借走同一试件；管理员提交旧弹窗应提示借用记录变化并刷新，B 仍借用中。再次打开确认框才可归还 B。另检查同一人归还后重新借用。
- 正常归还需携带页面看到的 loan_id_seen；检查请求体及归还人、说明。取消弹窗不发请求。旧客户端省略该字段返回 400，需更新并刷新页面。
- 缺陷整体替换遗漏类型、空条目应为字段级 400；无效请求不得改变原缺陷或修改历史。这些恶意/不完整请求由 API 回归验证，不在浏览器里通过写 fetch 伪造用户路径。

## 工作台提醒（待浏览器验收）

- 待补走：学生借一件试件、设到期日为昨天，工作台的**我借的试件**出现“已逾期”；同时准备今天到期和无到期日的借用，两者不能标逾期。记录真实总数和预览条数，点数字块验证 `mine=1`。
- 待补走：以管理员打开工作台，**逾期未还**只列本组已逾期未归还的借用，显示借用人；点数字块验证 `overdue=1` 列表。用导师和外组管理员复核无越界展示。

管理员从 /specimens?overdue=1 点击侧栏回到完整台账后，逾期复选框应取消，列表重新请求。已在集成实例通过 Chromium 验证。
