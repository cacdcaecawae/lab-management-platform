# 实验记录：新建、提交锁定、导师退回、修改历史

学生新建实验记录、关联自己的数据集、保存草稿、提交。提交后记录锁定，本人不能再改，并记下所引用数据集当时的版本。导师或管理员可以填写原因把记录退回为草稿，每次修改都留有历史。

## Sub-features

- `experiments-draft`：新建并"保存草稿"，出现提示"草稿已保存"，状态为"草稿"。
- `experiments-submit`：提交后出现提示"已提交，记录已锁定"，状态为"已提交"；本人页面不再有"保存草稿""提交"按钮，表单不可编辑，并显示"……提交，记录已锁定；如需修改，请联系导师退回。"
- `experiments-pin`：提交时记下关联数据集的版本；之后往该数据集追加文件，记录里显示的版本不变。
- `experiments-return`：导师在记录页点"退回"并填写原因后，出现提示"已退回"，状态回到"草稿"，本人可以再次编辑。
- `experiments-history`：点"修改历史"能看到提交和退回记录，包括退回原因。
- `experiments-isolation`：同组另一个学生打开这条记录，看到"记录不存在或无权查看"。

## How to get to it (user POV)

- 左侧展开 "科研记录" → menuitem "实验记录" → 按钮"新建实验记录"。
- 实验记录列表里点编号进入记录页。
- 记录页顶部的按钮："修改历史""退回""保存草稿""提交"。

## Driving it with chrome-devtools MCP

前提：

- 刚启动的实例。先按 `datasets.md` 用 `s_a` 建好 `DS-2026-0001` 并上传 `wave_001.csv`，用来测试关联和版本固定。
- 证据目录：`backend/var/verify-evidence/<日期>-experiments/`。

步骤：

- **新建草稿。** 以 `s_a` 登录，在左侧展开 "科研记录"、点 menuitem "实验记录"，点 button "新建实验记录"。点 combobox "*项目" 后按 `ArrowDown`、`Enter` 选"导波螺栓松动"；textbox "*实验名称" 填 `验证-螺栓预紧力扫描`；"*实验日期"的日期框填 `2026-11-17`；在"关联数据集（只能选择自己的数据集）"下拉框中用键盘选 `DS-2026-0001 验证-导波波形`。点 button "保存草稿"，用 `wait_for` 等 "草稿已保存"。
- **提交。** 点 button "提交"，用 `wait_for` 等 "已提交，记录已锁定"。状态标签为"已提交"，"保存草稿""提交"按钮消失，出现锁定说明。截图存证。
- **第二视角。** 运行 `bash .claude/skills/verify-lab/scripts/query.sh 'from research.models import Experiment; e = Experiment.objects.get(); print(e.status, e.data_versions)'`，输出 `submitted` 和 `{"1": "<64 位版本码>"}`。
- **版本固定。** 回到 `DS-2026-0001` 上传 `wave_002.csv`。再次运行上一步的查询，`data_versions` 不变。
- **导师退回。** 新开 `isolatedContext` 为 `adv` 的页面，用 `adv` / `Verify-2026!` 登录，从"实验记录"列表进入这条记录，点 button "退回"。对话框标题"退回实验记录"，在占位为"退回原因（必填）"的输入框填 `参数表缺少采样率`，点对话框的确认按钮。用 `wait_for` 等 "已退回"，状态变为"草稿"。
- **修改历史。** 在导师页面点 button "修改历史"，抽屉里能看到提交和退回两次变更，退回那条显示"原因：参数表缺少采样率"。截图存证。
- **本人可再编辑。** 回到 `s_a` 页面刷新，"保存草稿""提交"按钮重新出现。

- 导师在实验记录和处理记录列表按成员筛选。分别打开一条记录，点“复制为新草稿”，核对预填内容，点保存后才生成新记录；删除自己的新草稿，确认原记录仍可打开。

## Gotchas

- 日期框是 Element Plus 日期选择器，`fill` 填 `YYYY-MM-DD` 后要按 `Enter` 或点页面其他位置让它生效；提交前确认显示的日期。
- "关联数据集"下拉只列本人的数据集；学生乙看不到学生甲的数据集是预期行为。
- 退回对话框的确认按钮文字由 Element Plus 默认提供，以快照里实际显示的名称为准。
- 提交时 `title`、`date`、`project` 缺一项会报"提交前必须填写"。
