# 全站搜索

登录后从左侧栏打开搜索，按模块看有权查看的条目。

## Sub-features

- 学生与管理员看见不同范围，按模块展示。
- 结果链接和手机入口。
- `more-kinds`：能搜到成员、经费来源、报销（只有自己的；管理员、终审人看全组）、任务和里程碑（链接打开项目对应的标签）、行动项（打开组会）、数据文件名（打开所在数据集）。周报结果显示学生姓名，可以按姓名搜；组会结果显示日期，纪要里的词也能搜到。
- `code`：输入 `PR-2026-0001` 这样的完整编号，"采购申请"组里只有那一张。
- `keyboard`：输入后按 ↓ 高亮第一条（再按 ↓ 往下，↑ 往上），按回车打开高亮的那条，面板关闭。

## How to get to it (user POV)

左侧栏顶上 Phase 右边点 button "全站搜索"（放大镜图标）或在没有输入时按 `/`。页面中间出现搜索面板，背后变暗；点面板外面或按 Esc 关闭。

## Driving it with chrome-devtools MCP

分别以学生甲和学生乙创建标题包含同一关键字的实验记录。学生甲、管理员各开独立上下文，输入关键字并等待分组“实验记录”。学生甲仅看见自己的记录；管理员看见两条。点击结果应打开实验详情并关闭搜索面板。在 390px 宽度下重复打开、搜索和跳转。保存截图和快照。

## Gotchas

关键字最少 2 字，搜索只读。

- 同一列表点「显示全部」后，再次搜索并点击原成果/耗材，确认同一页仍定位刚选择的记录。知识库切到另一条后，必须先收起旧详情；目标加载失败不得继续显示旧文档。
- 在报销页用全站搜索先后打开两张报销单。让第一张的详情请求最后返回，确认弹窗仍显示第二张的编号、金额和说明。

无课题组运维账号打开系统管理，工具栏应隐藏全站搜索；按 / 也不打开搜索框。已在集成验证实例用 ops 复核。
