# Agent Note: 手机上单独一套界面骨架

Status: implemented

## Problem

- 手机上（宽 ≤ 768px）原来是把电脑版缩窄：
  - 顶上还是电脑那排标签，左上角一个方块图标开菜单，没有页面名。
  - 列表是电脑表格：14 个列表页的表格宽 510–1140px，手机上只露 324px，要左右滑。成员页右边固定的"操作"列占了 200px。
  - 筛选框一个占一行，表格上面先占掉 120–240px。
  - 卡片外边距加内边距，左右各吃掉 22px。
- 用户（2026-11-21）在手机宽度看了组会页："你这个根本不行，赶紧单独适配一下吧"。看了方案，导航选了底部标签栏。

## Decision

只在宽 ≤ 768px 时生效，电脑上不变。断点写在两处，必须一致：`layouts/phone.ts`（`matchMedia`）和 `theme.css`。

- **底部标签栏**（`layouts/PhoneTabBar.vue`）：
  - 四项：工作台、预约、通知（带未读数）、菜单。"菜单"打开原来的侧栏抽屉（账号名片、搜索、全部模块），在其他页面上它是选中的。
  - 运维账号没有课题组，只有系统管理，不显示底部栏，顶栏左边仍是菜单按钮。
  - "菜单"的读屏名沿用"打开菜单"，verify-lab 的 `responsive.py` 不用改。
- **顶栏**：
  - 只在列表页出现：左边页面名，右边是这一页的按钮。
  - `PageToolbar` 的 `#actions` 用 `Teleport` 移到顶栏的 `#phone-actions`，主按钮缩成小一号的胶囊。只有页面上第一个（不在弹窗、抽屉里的）工具栏能占用顶栏，后面的照旧留在原处，例如报销页"统计"tab 的按钮。
  - 有 `PageHeader` 的详情、编辑页没有顶栏：`PageHeader` 挂载时计数，计数不为 0 时顶栏隐藏，按钮也不移。
  - 电脑那排标签在手机上隐藏，后台照样记着。
- **列表变卡片**：
  - 所有 `el-table` 由 `theme.css` 里同一段样式改成一条一张：
    - 第一列（勾选框之后）是加粗的标题，状态标签放右上角。
    - 其余列是灰色小字"表头 值"，空的不显示。
    - "操作"列在底部右边。
  - 列名由 `labelTableCells`（`layouts/phone.ts`）从表头读出，写到每个格子的 `data-label`，同时标出空格子 `data-empty`。
  - `AppLayout` 用一个 `MutationObserver` 盯着 `<body>`（弹窗里的表格也要），每帧最多重写一次，只在手机宽度下运行。
- **筛选**：`PageToolbar` 在手机上只露出搜索框，下拉框、日期和筛选胶囊收在"筛选"图标后面。只有工具栏里确实有这几种控件时才出现这个图标。
- **弹窗**：`FormDialog` 在手机上 `fullscreen`，`theme.css` 让中间的表单滚动，标题和"取消 / 保存"固定。
- **详情字段**：`el-descriptions` 在手机上一行一对"名称 | 值"。
- **间距**：卡片内边距 16px，内容区左右 12px；有底部栏时内容区下面留 72px 加上 home 条的安全区（`viewport-fit=cover`）。
- **文档**：DESIGN.md 加"手机"一节；verify-lab 加 `features/phone.md`。

## Alternatives considered

- **每个列表页另写一份手机模板**：每页的卡片可以排得更讲究。但 26 处表格要写 26 份，加列时两边都要改。统一样式先把所有页变能用，个别页面以后再单独排。
- **只保留每页两三列的表格**：改动小，但还是表格，信息少一半，点进去才知道其他字段。
- **不加底部标签栏，只用左上角菜单**：用户选了底部栏。只用菜单的话，常用的预约、通知每次都要先开抽屉，单手也点不到左上角。
- **另做一个手机端（独立页面或小程序）**：体验最好，但要维护两套前端。

## Consequences

- 表头必须写清楚：卡片上的"表头 值"直接用表头文字，空表头的列在卡片上没有名字。
- `el-table` 自己按列宽算布局，卡片样式要用 `!important` 压住它的宽度和固定列；以后升级 Element Plus 时要用手机宽度看一遍列表。
- 卡片的列名在渲染之后才写上，数据刚到时有一帧没有列名。
- 自动场景 `responsive.py` 仍然只在 CI 的测试分支上跑，这次没在本机跑（没有 Selenium）。
- 验证：
  - 前端测试：列名和空格子的标记，数据变化后会更新；第一个工具栏的按钮移到顶栏，第二个留在原处，有 `PageHeader` 时不移；有下拉框时出现"筛选"，点开加上 `filters-open`。
  - 浏览器 390×844：
    - 成员、设备台账是卡片，页面宽 390、不左右滑；设备台账顶栏是两个图标加"新建设备"。
    - "筛选"点开后出现状态下拉和"校准到期"。
    - 设备详情没有顶栏，字段一行一对；"新建设备"弹窗 390×844 全屏，底部按钮贴底。
    - 报销页顶栏只有"登记报销"，"统计"的三个按钮留在卡片里。
    - "菜单"打开抽屉，有账号名片；点"通知"跳转，并变成选中。
    - 工作台没有顶栏。
  - 1440 宽：设备台账和改之前一样。
