# Agent Note: 实验记录的设备字段先用文本（原 D9）

Status: implemented

## 问题

实验记录需要写明使用的设备，但设备台账排在第二期，第一期没有设备表可以引用。

## 决策

`Experiment.equipment` 是文本字段。

## 曾考虑的替代方案

- **第一期就建设备表并用外键**：数据更规范；但设备台账整体排在第二期。

## 后果

- 收益：第一期不依赖设备模块。
- 原定的退出条件是"第二期上线设备台账时改为外键并迁移数据"。2026-11-17 第二期改为：新增可空外键 `equipment_item`（台账设备），文本字段保留并改称"设备说明"，不做数据迁移，理由见 [第二期设备与耗材](../feature/2026-11-17-phase2-equipment-and-consumables.md)。本笔记的决策（文本字段）因此继续有效，只是不再是唯一的设备字段。
