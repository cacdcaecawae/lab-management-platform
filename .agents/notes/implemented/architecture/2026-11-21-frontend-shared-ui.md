# Agent Note: 前端统一界面：DESIGN.md、类苹果风主题、飞书式侧栏、共用弹窗 / 工具栏 / 页头 / 表单栅格、新工作台和预约页

Status: implemented

## Problem

2026-11-21 用户本地验证 v0.1.2 时指出"新建里程碑"弹窗的保存按钮挤在"标为完成"后面，问前端是不是每页各写各的，又说整体风格"临时搓出来的，不清晰、费眼睛"，预约日历"好奇怪"、看下个月要一周一周翻。用验证实例（`mgr`，1440×900）逐页截图并对照代码，结论：列表的数据逻辑是共用的（`usePagedList`、`useOptions`、`StatusTag`、`HistoryDrawer`、`utils/errors`），**界面骨架和规范都没有**。第一期各模块由子代理并行写，仓库里没有任何界面规范（只有 `theme.css` 开头 4 行注释），也没有检查拦住走样：

- **弹窗**：23 个 `el-dialog` 宽度有 10 种（420–900px）。项目页"新建任务""新建里程碑"把"保存"放进表单最后一行、没有"取消"，必填的标题没有星号。
- **表单分栏**：14 个文件各用 `el-row` / `el-col` 定 span，同一个弹窗里上下两行的列宽不一样。
- **列表工具栏**：`.page-toolbar` 是一行可换行的 flex，筛选一多，主按钮被挤到第二行最左边。
- **详情 / 编辑页**：三种布局（卡片头右上角、卡片外底部吸底栏、卡片外标题加卡片内底部按钮）。
- **用词**：新建按钮有"新建""新增""登记"；弹窗主按钮有"保存""创建"；草稿按钮有"保存草稿"和"保存"；空列表有"暂无""还没有""没有"。
- **看不清**：次要文字 `#8f8f8f` 对白底约 3.2:1，表头 12px 灰字，边框 `#ececec` 约 1.2:1；按钮、链接、选中菜单、自己的预约都是黑或灰，没有重点；页面和卡片都是白的，没有层次；复选框因 `--el-border-radius-small` 是圆的。
- **预约日历**：`contentHeight: 620` 在卡片里再滚动，Windows 上冒出滚动条箭头，0–8 点藏在上面；日历自带的翻页按钮和站内按钮两套样式；表头挤成"11/16周一"；只有周、日视图，没有选日期跳转。
- **宽屏**：内容区限 1200px 居中，1920 宽时菜单和内容之间空一大块。
- **第一版之后用户又指出**（看了 PR #39 的管理员页面）：顶栏的搜索框和通知铃铛弹层能同时打开、叠在一起；整体"很 AI、全是拼在一起的"，并给了飞书的截图作参考。对照来看，工作台是一墙等大的数字卡片加十几张卡片，空的也各占一个框；顶栏右侧挂了三个各自弹出的东西（搜索、铃铛、账号）。飞书是左侧栏放账号、搜索和带红色数字的菜单，右边只有内容面板。
- **第二版之后用户又指出**：账号菜单往下弹，盖住搜索框和"通知"；左侧菜单管理员有 21 项，比笔记本屏幕还高；工作台"还是好奇怪"：顶栏写"工作台"、下面又是大字问候，"要处理"卡片宽 1100 多像素、名字在最左日期在最右，小标题、粉色数字泡、灰字"没有待处理"层层叠叠。用户从三个方案里选了"左边只放模块，上面切页面"。
- **第五版之后用户提议**（附网易邮箱截图：固定标签后面跟着打开过的邮件，可关闭）：点开的记录也做成标签，"这样不用返回去点了"。现在看两条实验记录、或在设备和采购单之间来回，每次都要回列表再点。另外查到编辑页从来没有离开前提醒：写到一半点一下菜单，内容直接丢。
- **第六版之后用户又提出**：问"项目为啥和组会在一起"——组会没有"属于哪个项目"这一项，项目连着的是实验记录、数据集；周报和组会才是一回事（每周写周报、组会上汇报、会后领行动项），却分在"科研记录"和"项目"两处。随后给了飞书侧栏的截图：分组可以收起展开，收起时左边是彩色图标、展开时才是箭头；要求"标签还留着，只是公用了"，不同类别用颜色区分，标签一开始没有、点开一个才有。
- **第三版之后用户又指出**：工作台"还是不得劲"，不明白左右两张卡片为什么这么分；问能不能多用"圆角气泡"（像状态标签那样的胶囊），整体再润色一版。1920 宽时工作台限宽 1120px，右边空出一大块；类型是一列红 / 灰字，和行尾的"待检查"标签重复；日程按天的小标题加分隔线，层次不清。

## Decision

- **侧栏和顶栏（飞书式）**：左侧栏和页面同一种灰、没有分隔线，从上到下是账号（头像、姓名、课题组，点开修改密码、退出登录）、搜索框、菜单（`layouts/SideNav.vue`，桌面侧栏和手机抽屉共用）。通知铃铛去掉，菜单里加"通知"，未读数是红色数字；轮询未读数从铃铛组件挪到 `useNotificationPolling`，在 `AppLayout` 里只跑一份。搜索改成页面中间的搜索面板，背后变暗，点外面或 Esc 关闭；侧栏是 sticky，自带层叠上下文，所以侧栏 `z-index: 20` 才能让面板盖住页面。按 `/` 只由屏幕上看得见的那个搜索框响应（桌面侧栏和手机抽屉各有一个）。顶栏只留页面名（第三版改成页面标签，见下一条）。卡片去掉描边，只留阴影和标题下的分隔线；当前菜单是白色胶囊。
- **模块菜单和页面标签（第三版）**：模块和每个模块的页面写在 `layouts/nav.ts` 一处。侧栏只列模块（工作台、通知、科研记录、设备耗材、采购经费、项目、知识成果、成员、系统管理，按角色过滤，管理员 8 项）；有几页的模块，顶栏是这些页面的标签，详情页标亮它所属的列表页（`meta.menu`）；页面名仍是一个看不见的 `h1`。点模块回到这个模块上次打开的那一页（只记在内存里，刷新后回到第一页）。只有一页的模块顶栏显示页面名；工作台在电脑上没有顶栏，问候就是标题。账号菜单在侧栏右边弹出。
- **工作台**：去掉数字卡片和十几张卡片，改成两张卡片。第三版："要处理"是一张平铺清单，一件事一行，行首是类型（"校准到期""库存不足"……，要紧的类型红字、排在前面），每类最多 5 行，多的一行"全部 N 条"进筛选列表；没有内容的类型不出现。"我的日程"按天分组列预约（"11/23周一"下面"09:00 – 11:00 UT-001 超声探伤仪"），前面是本周周报，后面是我借的试件，空的不出现。整页限宽 1120px，免得条目和后面的日期隔太远。第四版：两张卡片改名"需要你处理"（只有你能推进的事）和"接下来"（已经排好、只要记着的事），名字本身说明为什么分两边；不再限宽。每行整行可点，类型是胶囊标签（要紧的红、其余灰），后面两行字（哪一件 / 灰字细节），最右 `>`，行间不画线、悬停浅灰圆角底，日期细节在条目下面而不是行尾，所以宽屏也不远；和类型重复的状态标签去掉（设备待检查、待反馈周报、周报需补充）。"接下来"每天左边一块撕页日历样的日期块（月 / 日 / 星期，今天蓝底），右边设备和时间。
- **打开过的记录标签（第六版）**：`layouts/nav.ts` 记下打开过的记录（有 `meta.menu` 的路由，除了 `*-new` 表单），`AppLayout` 把它们排在当前模块的页面标签后面，每个带"关闭 <标题>"按钮；起初只显示当前模块的（每模块 6 个），用户指出"切换到其他地方应该也存在"，改成全局一份、在每一页都显示（包括工作台、通知、成员，这些地方顶栏只有记录、下面多留 20px），最多 8 个（多了丢最早的），点一条会跳到它的模块，同一条记录只占一个（地址里的查询参数随最近一次）。标签名由 `PageHeader` 在渲染后读自己的标题文字报上来（9 个详情页不用各改）；保存新记录时地址从 `/new` 换成 `/<id>`，`PageHeader` 也按地址变化重报一次。关掉当前标签回列表页；组会、采购草稿删除后关掉自己的标签。存在 `sessionStorage`（`lab.tabs`，带用户 id：换人登录清空，退出也清空）。点模块回到"上次打开的那一页"改成记完整地址，所以也可以回到一条记录。打印标签页在主界面外面，不算。用户随后要求顶栏标签"不要气泡，像网页邮箱那样"：先试了"灰标签站在 2px 蓝线上、当前蓝底白字"，用户嫌蓝线奇怪；改成浏览器标签那样：灰底、上面两个角 10px 圆，当前的白色、和下面的白卡片连成一片（主区域上边距为 0；标签条左边空 16px、`scroll-padding-inline: 16px`，标签落在卡片圆角之后的直边上，手机上滚到最右也一样），页面标签和记录标签同一种样子，中间空 10px；顶栏标签因此是"圆角气泡"规则的例外。新建页不是标签（切走再回来是空表单，标签会让人以为内容还在；保存草稿后才出现这条记录的标签）——实现时改了先前对用户的说法，向用户说明后用户选了这个。
- **可收起的侧栏分组 + 共用标签（第七版，取代第三版的"侧栏只列模块、顶栏是模块的页面"和第六版的"页面标签后面跟记录"）**：
  - 分组改成：工作台、通知，项目（单独一项）、科研记录（实验记录、原始数据、数据处理）、周报组会（周报、组会）、设备耗材、采购经费、知识成果，成员。
  - 侧栏用 `el-sub-menu`：有几页（按角色过滤后）的模块是一组，组的菜单 index 是 `g:<key>`（Element Plus 把顶层菜单项也记进组表，并在启动时对它们报 `open`，所以只认 `g:` 开头的）。收起时左边是模块颜色的色块加白色图标，展开时那个位置换成浅色底上的向下箭头，Element Plus 自带的右侧箭头藏掉；子项缩进 42px，和组名对齐。正在看的页所在的组自动展开（`menu.open`），离开时如果不是自己点开的就收起（`menu.close`，不发事件）；自己点开 / 收起的记进 `localStorage`（`lab.menu.open`），只认用户点击（当前组的 `open` 事件不记）。
  - 每个业务模块一个颜色（`theme.css` 的 `--lab-mod-*`：项目青、科研记录蓝、周报组会紫、设备耗材橙、采购经费绿、知识成果粉，白色图标在上面都不低于 3:1），只用在侧栏图标和顶栏标签的圆点；工作台、通知、成员是灰色线条图标。
  - 顶栏只剩一排共用标签：一开始没有，打开任一页（列表页或记录；工作台、运维的系统管理和 `*-new` 表单除外）就多一个，按地址去重，最多 10 个；每个标签前面是所属模块颜色的圆点（由标签地址解析出页面，再查 `nav.ts`），后面是 ×。关掉正在看的，换到它右边那个，没有就左边，都没有回工作台。没有标签时顶栏显示页面名；有标签但正在看的页不在其中时，标签下面留 20px。去掉了"点模块回到上次那一页"。
- **离开前提醒（第六版）**：`composables/useUnsavedGuard.ts`：表单和"上次填进表单时"的 JSON 快照不同、且页面可编辑时，`onBeforeRouteLeave` / `onBeforeRouteUpdate`（换了 id）弹"离开这一页"确认，`beforeunload` 让浏览器自己问。实验记录、数据处理、周报、采购申请在 `fill()` 末尾、组会在 `startEdit()` 末尾调 `markSaved()`；快照当场取一次（保存后紧接着换地址，守卫在之后的微任务里才跑），下一拍再取一次（等参数编辑器这类子组件把表单整理完，免得一打开就算"改过"）。删除后跳走前也调一次。
- **自查一轮（第五版）**：用户要求不要等他指出，自己逐页找问题，并问工作台能不能手动拖。逐页（1440 宽，`mgr`）看下来改了：卡片里的 `el-tabs`（周报、报销、项目详情、系统管理）从下划线改成和顶栏一致的分段胶囊；工具栏里的是 / 否筛选复选框改成筛选胶囊（只用 CSS，真实复选框仍在，键盘、读屏照旧）；标签去掉描边；20 张表格从默认"暂无数据"改成"暂无 X"；耗材每行 7 个操作折成两行，管理员改成"领用""退回"加"更多"下拉（学生、导师本来只有三个，"流水"直接露出）；工具栏是卡片最后一个元素时不再留底边距（成员页注册卡片太高）；通知页标题"站内通知"改成和菜单一致的"通知"。工作台问候下面加一行概况；两栏之间的空隙可以拖动调整右栏宽度（300–720px、CSS 再限最多一半，拖动也只跟到这一半；←/→ 每次 24px，双击恢复 400px，存在 `localStorage`）。
- **圆角气泡（第四版）**：按钮、标签、搜索框、顶栏页面标签、分段切换（`el-radio-button`，灰轨道上的白胶囊，不再是蓝底按钮组）都是胶囊形；当前页面标签和侧栏当前模块一样是白胶囊加淡阴影；卡片、弹窗圆角 16px；标签字号 13px（Element Plus 默认 12px）。都在 `theme.css` 和两个布局文件里，页面没动。
- **规范**：仓库根目录 `DESIGN.md` 写颜色、字号、圆角、阴影、间距的取值，列表页 / 详情页 / 弹窗 / 表单 / 预约日历用哪个共用组件、按钮放哪，用词表，空 / 加载 / 出错 / 确认的写法，对比度下限。AGENTS.md 加"界面"一节：改前端先读它。
- **主题（类苹果风）**：`theme.css` 重写变量：页面底色 `#f5f5f7`、侧栏 `#ebebef`、白卡片带很淡的阴影；蓝色 `#0071e3` 只用在主按钮、链接（`#0066cc`）、选中的菜单和自己的预约；文字三档 `#1d1d1f` / `#3a3a3c` / `#6e6e73`，白底上都不低于 4.5:1；输入框边框 `#c7c7cc`；表头 13px 深色加底色；复选框 4px 圆角；关着的开关 `#8e8e93`。中文最小 13px，页面里写死的 12 / 12.5px 和颜色改成变量。毛玻璃只在顶栏，`prefers-reduced-transparency`、`forced-colors` 和不支持 `backdrop-filter` 时是实色。内容区不再限宽居中。`dayjs/locale/zh-cn` 在 `main.ts` 加载，所有日期选择器周一开头。
- **共用组件**（`frontend/src/components/`）：
  - `FormDialog`：`el-dialog` + 标签在上的 `el-form` + 右下角"取消 / 主按钮"；宽度 `sm` 460 / `md` 620 / `lg` 800；`readonly` 时表单变灰、只留"关闭"；`#before` / `#after` 放表单外的内容，`#extra` 放左下角的删除，`#actions` 放主按钮后的按钮；"取消"走 `handleClose`，所以 `before-close` 照样生效。21 个带表单的弹窗都改用它（含预约详情、项目页两个）；成果统计、本组存储用量这种只展示的仍是 `el-dialog`。
  - `PageToolbar`：默认插槽放筛选（左侧，放不下换行），`#actions` 放按钮（固定右上角）。22 个工具栏、通知页、任务看板都改用它。右侧最多两个次要按钮加主按钮：设备台账去掉"预约日历"（菜单下一项就是），成果的两种导出合成"导出"下拉。
  - `PageHeader`：卡片头里"返回 + 标题 + `#tags` 状态 + 右侧按钮"。9 个详情 / 编辑页改用它；其中采购申请的吸底操作栏搬进页头，审批意见和"退回修改 / 通过"放在页面最后的"审批"卡片里；组会的返回、标题、按钮搬进卡片头；项目详情的进展 / 任务 / 里程碑放进一张卡片。
  - `.form-grid`（`theme.css`）：`repeat(auto-fill, minmax(180px, 1fr))`，`.span-2` / `.span-all` 占两列 / 整行；替换全部 `el-row` / `el-col`。整页表单加 `.form-page`（最宽 960px）。
- **预约页**：右侧栏是 Element Plus 的 `el-date-picker-panel` 小月历（点哪天跳到那天）、"只看我的"、"全部设备"和每台设备的复选框；每台设备一个颜色（按列表顺序取 8 色），自己的预约实心、别人的浅色加左边线、维护是斜纹。日历用 FullCalendar 的月 / 周 / 日（新增依赖 `@fullcalendar/daygrid`，与已有的 6.1.22 同版本），自带表头关掉，翻页、今天、视图切换用站内按钮；`height: 'auto'`，一小时一格（32px），拖选按半小时对齐，一天 24 小时都在页面上，表头吸在顶栏下面；周视图表头"周一 / 11/16"两行；月视图事件是彩色条，点日期进入那天。只勾一台设备时地址带 `?equipment=`，和以前从设备详情跳过来一样。
- **用词**：新建统一"新建 X"；弹窗主按钮"保存"（预约、借用、重置、登记这类专门动作用动作本身）；草稿"保存草稿"；空列表"暂无 X"，筛选后为空仍是"没有符合条件的……"。
- **检查**：`components.test.ts` 读 `src/modules/**/*.vue` 源码，`el-dialog` 里有表单、用 `el-row` / `el-col`、`class="page-toolbar"`、`el-page-header`、按钮或标题以"新增"开头都会失败。
- 改名的按钮和布局同步写进 `.claude/skills/verify-lab/features/`（设备、耗材、试件、经费、成果、周报、组会、采购、数据集、任务看板）。业务逻辑和接口不动。

## Alternatives considered

- **只修截图里看到的几处**：改动最小。但原因（没有共用骨架、没有规范、没有检查）不变，下一个新页面还会走样，用户明确不接受"一处一处补"。
- **换成现成的后台模板（Vue Pure Admin 一类）**：一次得到成套布局。但要重写路由、布局、权限菜单和全部页面，现有前端测试大多要重写；问题只是几个骨架件没共用。
- **换成 shadcn-vue**（用户同事提议）：组件长相现代。但要重写 57 个文件里的表格、日期选择、下拉、弹窗、确认框和表单校验，引入 Tailwind，27 个测试文件以 `ElementPlus` 插件挂载；宽度不一、按钮位置、用词混用是用法问题，换库照样会有；它默认的黑白灰正是被嫌弃的样子。Fable 独立评估（2026-11-21）结论相同。
- **大面积毛玻璃**（同事提议"参考苹果的毛玻璃"）：最像苹果新系统。但表格和表单在半透明层下对比度变差，正是"费眼睛"的来源；纯灰底上看不出效果；集成显卡和远程桌面上滚动会掉帧。苹果自己也只把玻璃用在浮在内容上的导航层。
- **只写规范、不做组件**：最省代码，但第一期就是靠各自理解写的，没有组件和检查拦不住。
- **基于 Element Plus 的增强库（plus-pro-components）**：自带弹窗表单、搜索栏。但还是 0.1 版，表单要改成配置写法，等于重写所有表单，只为省一百来行。
- **预约日历在卡片里滚动（固定高度，`scrollTime` 8 点）**：日历应用常见做法。但正是用户嫌"框里套框"、0–8 点看不见的原因；一小时 32px 时一整天 768px，1080p 屏幕上几乎一屏看完。
- **预约只加日期跳转、不加月视图**：不加依赖。但看不出一个月里哪几天已经约满；daygrid 是同一套 FullCalendar 的官方插件。
- **保留铃铛，只让两个弹层互斥（点开一个关掉另一个）**：改动最小，修好了叠在一起。但顶栏仍然挂着三个各自弹出的小东西，正是"拼起来"的感觉；铃铛弹层里只有标题和时间，点进去还是要到通知页。飞书用菜单上的红色数字。
- **工作台保留数字卡片，只把空卡片藏起来**：改动小。但一排数字和下面的列表说的是同一件事，看两遍；数字卡片墙是用户说的"AI 感"的主要来源。
- **记录标签按模块分开**（先做的版本）：一排标签都是同一类东西，固定标签不会因为点了别的模块的记录而整排换掉。但用户要的就是像邮箱那样一直在，跨模块来回（实验记录和它用的设备）才是最常见的用法。
- **把切走的页面留在内存里（`KeepAlive`）**：切回来连没写完的内容都在。但看到的可能是旧数据（几个人一起改记录），还要处理每页"重新激活时刷新"；改成"切回来重新加载 + 离开前提醒"。
- **只靠浏览器标签页**（表格里的名称是真链接，Ctrl+点击就开新标签页）：零改动，但大多数人不知道，而且每个标签页各自登录状态、各占一份内存。
- **菜单分组折叠**（第三版的方案 B）：Element Plus 自带，改动最少。第三版时没选：去别的组要先展开，菜单高度随展开收起跳动。第七版用户指定了它；有了共用标签，常去的页都在顶栏，侧栏用得少了，这个缺点影响不大。
- **侧栏只列模块、顶栏是当前模块的几页加打开的记录**（第三到第六版）：侧栏短、一屏放得下。但顶栏的固定页随模块整排换掉，学生常用的实验记录、周报、设备预约分在三个模块里，来回都要先点模块。
- **项目和组会仍放一组**（只改名"项目与组会"）：不用改。但两者在数据上没有关系，周报和组会反而被拆开。
- **项目放进科研记录第一页、侧栏仍 8 项**：项目 → 实验 → 数据 → 处理连成一条线。但导师、管理员常单独看项目，藏在科研记录里不显眼。
- **只压缩菜单间距**（方案 C）：结构不变。但只降到约 650px，笔记本上仍要滚动。
- **采购审批保留吸底栏**：手机上审批按钮一直在手边。但和其他页面不一致，还多一块毛玻璃；审批前本来就要看完整个申请，按钮在页面最后不费事。

## Consequences

- 以后换风格只改 `theme.css` 和三个共用组件；新页面照 `DESIGN.md` 写，走样的写法会被源码检查拦下。代价是共用组件要随 Element Plus 升级一起看（`FormDialog` 用了 `el-dialog` 暴露的 `handleClose`）。
- 设备台账没有"预约日历"按钮了，走菜单"设备预约"；成果导出多点一下下拉。
- 没有铃铛弹层了，看通知要进"通知"页（菜单第二项）；品牌名"课题组管理"不再出现在侧栏，只在登录页和浏览器标签上。
- 采购审批在手机上要滚到页面最后才能点"通过"。
- 侧栏所有组都展开时管理员有二十多行，要滚动；平时只开一两组。顶栏标签超过一屏宽时横向滚动，没有"全部标签"下拉。
