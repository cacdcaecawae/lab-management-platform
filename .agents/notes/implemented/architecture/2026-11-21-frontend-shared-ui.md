# Agent Note: 前端统一界面：DESIGN.md、类苹果风主题、共用弹窗 / 工具栏 / 页头 / 表单栅格、新预约页

Status: implemented

## Problem

2026-11-21 用户本地验证 v0.1.2 时指出"新建里程碑"弹窗的保存按钮挤在"标为完成"后面，问前端是不是每页各写各的，又说整体风格"临时搓出来的，不清晰、费眼睛"，预约日历"好奇怪"、看下个月要一周一周翻。用验证实例（`mgr`，1440×900）逐页截图并对照代码，结论：列表的数据逻辑是共用的（`usePagedList`、`useOptions`、`StatusTag`、`HistoryDrawer`、`utils/errors`），**界面骨架和规范都没有**。第一期各模块由子代理并行写，仓库里没有任何界面规范（只有 `theme.css` 开头 4 行注释），也没有检查拦住走样：

- **弹窗**：23 个 `el-dialog` 宽度有 10 种（420–900px）。项目页"新建任务""新建里程碑"把"保存"放进表单最后一行、没有"取消"，必填的标题没有星号。
- **表单分栏**：14 个文件各用 `el-row` / `el-col` 定 span，同一个弹窗里上下两行的列宽不一样。
- **列表工具栏**：`.page-toolbar` 是一行可换行的 flex，筛选一多，主按钮被挤到第二行最左边。
- **详情 / 编辑页**：三种布局（卡片头右上角、卡片外底部吸底栏、卡片外标题加卡片内底部按钮）。
- **用词**：新建按钮有"新建""新增""登记"；弹窗主按钮有"保存""创建"；草稿按钮有"保存草稿"和"保存"；空列表有"暂无""还没有""没有"。
- **看不清**：次要文字 `#8f8f8f` 对白底约 3.2:1，表头 12px 灰字，边框 `#ececec` 约 1.2:1；按钮、链接、选中菜单、自己的预约都是黑或灰，没有重点；页面和卡片都是白的，没有层次；复选框因 `--el-border-radius-small` 是圆的。
- **预约日历**：`contentHeight: 620` 在卡片里再滚动，Windows 上冒出滚动条箭头，0–8 点藏在上面；日历自带的翻页按钮和站内按钮两套样式；表头挤成"11/16周一"；只有周、日视图，没有选日期跳转。
- **宽屏**：内容区限 1200px 居中，1920 宽时菜单和内容之间空一大块。

## Decision

- **规范**：仓库根目录 `DESIGN.md` 写颜色、字号、圆角、阴影、间距的取值，列表页 / 详情页 / 弹窗 / 表单 / 预约日历用哪个共用组件、按钮放哪，用词表，空 / 加载 / 出错 / 确认的写法，对比度下限。AGENTS.md 加"界面"一节：改前端先读它。
- **主题（类苹果风）**：`theme.css` 重写变量：页面底色 `#f5f5f7`、侧栏 `#ebebef`、白卡片带很淡的阴影；蓝色 `#0071e3` 只用在主按钮、链接（`#0066cc`）、选中的菜单和自己的预约；文字三档 `#1d1d1f` / `#3a3a3c` / `#6e6e73`，白底上都不低于 4.5:1；输入框边框 `#c7c7cc`；表头 13px 深色加底色；复选框 4px 圆角；关着的开关 `#8e8e93`。中文最小 13px，页面里写死的 12 / 12.5px 和颜色改成变量。毛玻璃只在顶栏，`prefers-reduced-transparency`、`forced-colors` 和不支持 `backdrop-filter` 时是实色。内容区不再限宽居中。`dayjs/locale/zh-cn` 在 `main.ts` 加载，所有日期选择器周一开头。
- **共用组件**（`frontend/src/components/`）：
  - `FormDialog`：`el-dialog` + 标签在上的 `el-form` + 右下角"取消 / 主按钮"；宽度 `sm` 460 / `md` 620 / `lg` 800；`readonly` 时表单变灰、只留"关闭"；`#before` / `#after` 放表单外的内容，`#extra` 放左下角的删除，`#actions` 放主按钮后的按钮；"取消"走 `handleClose`，所以 `before-close` 照样生效。21 个带表单的弹窗都改用它（含预约详情、项目页两个）；成果统计、本组存储用量这种只展示的仍是 `el-dialog`。
  - `PageToolbar`：默认插槽放筛选（左侧，放不下换行），`#actions` 放按钮（固定右上角）。22 个工具栏、通知页、任务看板都改用它。右侧最多两个次要按钮加主按钮：设备台账去掉"预约日历"（菜单下一项就是），成果的两种导出合成"导出"下拉。
  - `PageHeader`：卡片头里"返回 + 标题 + `#tags` 状态 + 右侧按钮"。9 个详情 / 编辑页改用它；其中采购申请的吸底操作栏搬进页头，审批意见和"退回修改 / 通过"放在页面最后的"审批"卡片里；组会的返回、标题、按钮搬进卡片头；项目详情的进展 / 任务 / 里程碑放进一张卡片。
  - `.form-grid`（`theme.css`）：`repeat(auto-fill, minmax(180px, 1fr))`，`.span-2` / `.span-all` 占两列 / 整行；替换全部 `el-row` / `el-col`。整页表单加 `.form-page`（最宽 960px）。
- **预约页**：右侧栏是 Element Plus 的 `el-date-picker-panel` 小月历（点哪天跳到那天）、"只看我的"、"全部设备"和每台设备的复选框；每台设备一个颜色（按列表顺序取 8 色），自己的预约实心、别人的浅色加左边线、维护是斜纹。日历用 FullCalendar 的月 / 周 / 日（新增依赖 `@fullcalendar/daygrid`，与已有的 6.1.22 同版本），自带表头关掉，翻页、今天、视图切换用站内按钮；`height: 'auto'`，一小时一格（32px），拖选按半小时对齐，一天 24 小时都在页面上，表头吸在顶栏下面；周视图表头"周一 / 11/16"两行；月视图事件是彩色条，点日期进入那天。只勾一台设备时地址带 `?equipment=`，和以前从设备详情跳过来一样。
- **用词**：新建统一"新建 X"；弹窗主按钮"保存"（预约、借用、重置、登记这类专门动作用动作本身）；草稿"保存草稿"；空列表"暂无 X"，筛选后为空仍是"没有符合条件的……"。
- **检查**：`components.test.ts` 读 `src/modules/**/*.vue` 源码，`el-dialog` 里有表单、用 `el-row` / `el-col`、`class="page-toolbar"`、`el-page-header`、按钮或标题以"新增"开头都会失败。
- 改名的按钮和布局同步写进 `.claude/skills/verify-lab/features/`（设备、耗材、试件、经费、成果、周报、组会、采购、数据集、任务看板）。业务逻辑和接口不动。

## Alternatives considered

- **只修截图里看到的几处**：改动最小。但原因（没有共用骨架、没有规范、没有检查）不变，下一个新页面还会走样，用户明确不接受"一处一处补"。
- **换成现成的后台模板（Vue Pure Admin 一类）**：一次得到成套布局。但要重写路由、布局、权限菜单和全部页面，现有前端测试大多要重写；问题只是几个骨架件没共用。
- **换成 shadcn-vue**（用户同事提议）：组件长相现代。但要重写 57 个文件里的表格、日期选择、下拉、弹窗、确认框和表单校验，引入 Tailwind，27 个测试文件以 `ElementPlus` 插件挂载；宽度不一、按钮位置、用词混用是用法问题，换库照样会有；它默认的黑白灰正是被嫌弃的样子。Fable 独立评估（2026-11-21）结论相同。
- **大面积毛玻璃**（同事提议"参考苹果的毛玻璃"）：最像苹果新系统。但表格和表单在半透明层下对比度变差，正是"费眼睛"的来源；纯灰底上看不出效果；集成显卡和远程桌面上滚动会掉帧。苹果自己也只把玻璃用在浮在内容上的导航层。
- **只写规范、不做组件**：最省代码，但第一期就是靠各自理解写的，没有组件和检查拦不住。
- **基于 Element Plus 的增强库（plus-pro-components）**：自带弹窗表单、搜索栏。但还是 0.1 版，表单要改成配置写法，等于重写所有表单，只为省一百来行。
- **预约日历在卡片里滚动（固定高度，`scrollTime` 8 点）**：日历应用常见做法。但正是用户嫌"框里套框"、0–8 点看不见的原因；一小时 32px 时一整天 768px，1080p 屏幕上几乎一屏看完。
- **预约只加日期跳转、不加月视图**：不加依赖。但看不出一个月里哪几天已经约满；daygrid 是同一套 FullCalendar 的官方插件。
- **采购审批保留吸底栏**：手机上审批按钮一直在手边。但和其他页面不一致，还多一块毛玻璃；审批前本来就要看完整个申请，按钮在页面最后不费事。

## Consequences

- 以后换风格只改 `theme.css` 和三个共用组件；新页面照 `DESIGN.md` 写，走样的写法会被源码检查拦下。代价是共用组件要随 Element Plus 升级一起看（`FormDialog` 用了 `el-dialog` 暴露的 `handleClose`）。
- 设备台账没有"预约日历"按钮了，走菜单"设备预约"；成果导出多点一下下拉。
- 采购审批在手机上要滚到页面最后才能点"通过"。
- 新增前端依赖 `@fullcalendar/daygrid`、`dayjs`（后者本来就是 Element Plus 的依赖，写进 `package.json` 是因为 `main.ts` 直接引用它的中文语言包）。
- 只在电脑宽度（1440）逐页看过；手机宽度只看了预约页的布局规则（侧栏排到日历下面），其余页面没逐页看。删除确认框（`ElMessageBox.confirm`）没改。
- 验证：
  - `vue-tsc` 无错误；前端 41 个文件 136 个测试通过（含 4 个新的源码检查）。把 `main` 上的 `ProjectBoard.vue`、`EquipmentView.vue`、`RunEditView.vue` 临时放进 `src/modules/`，4 个源码检查都失败、并指出这几个文件；删掉后通过。
  - node:24-alpine 里从新的 lockfile `npm ci`、测试、构建都通过；lockfile 只多了 `@fullcalendar/daygrid` 和 `dayjs` 两行，`@emnapi` 条目还在。
  - 验证实例（`mgr`，1440×900，证据在 `backend/var/verify-evidence/2026-11-21-ui/`）：建了 4 台设备、10 条预约（含 `s_a` 的和一条维护）。周视图按设备着色、整天在页面上、表头吸在顶栏下（滚动后表头 top 52px）；月视图彩色条、今天高亮；小月历周一开头、宽度合适。"新建试件"是 800px 三列对齐、右下角"取消 / 保存"，工具栏按钮在右上角、筛选换到第二行左边。"新建里程碑"标题有星号、没填时"保存"变灰，填了标题保存后列表出现这条里程碑。实验记录、采购申请新建页按钮都在卡片头右上角。工作台的数字卡片是白底。
