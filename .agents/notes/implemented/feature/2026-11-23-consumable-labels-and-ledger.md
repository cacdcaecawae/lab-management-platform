# Agent Note: 耗材二维码标签、扫码领用和入库，跨耗材流水总账与导出（issue #48 N7）

Status: implemented

## Problem

- 设备和试件已经能打印二维码标签，扫码直达详情页；耗材没有标签。实验台边领一瓶耦合剂，要掏手机打开耗材页，再搜名字、点"领用"。
- 出入库流水只能一个耗材一个耗材地看（行内"流水"抽屉）。管理员月底对账、导出一段时间内全组的领用和入库，没有地方做。
- 相关决定：[设备和试件二维码标签](./2026-11-18-qr-labels.md)、[第二期设备与耗材](./2026-11-17-phase2-equipment-and-consumables.md)。

## Decision

- **耗材标签**：标签页加 `type=consumable`，和设备、试件同一套排版；标签上是二维码、名称、规格 · 存放位置（耗材没有编号）。耗材列表给管理员加勾选列和"打印标签"。二维码内容是 `/consumables?item=<id>&scan=1`。
- **扫码领用和入库**：带 `scan=1` 打开时列表只显示这一种（原有的 `?item=`），这一行一出现就弹出"领用"，数量默认 1；管理员的弹窗顶上可以切到"入库"。没登录时先登录再回来，复用标签扫码的回跳。领用的批次、库存校验都是原来那个对话框的。
- **流水总账**：`GET /api/stock-txns/`（本组）和 `.../export/`：
  - 导师、管理员看全组，其他人只看自己经手的。
  - 筛选：耗材、类型、经手人、项目、日期范围；最新在前、分页；导出与页面同样的范围和筛选。
  - 每条在 `StockTxn` 之外带上是哪种耗材（名称、规格、单位）。
  - 耗材页加"流水"标签（`?tab=ledger`），项目"资产"里的耗材块也用它（`?project=`）。

## Alternatives considered

- **二维码直接指向一个"快速领用"独立页面**：页面更简单；但要另写权限和批次选择，耗材列表里的领用对话框已经处理了批次和库存版本，直接复用更不容易出错。
- **总账用现有每个耗材的流水接口拼**：不改后端；但跨耗材的筛选和导出做不了，耗材多了以后要发很多请求。
- **学生在总账里也看全组**：对账更方便；但领用人、项目是谁的事，issue 说学生只看自己经手的；行内"流水"抽屉仍然是组内公开的。

## Consequences

- 测试：`inventory/tests/test_ledger.py`（谁看到哪些、筛选、导出与列表一致、非法日期 400）；前端 `LabelsView.test.ts`（耗材标签的地址和文字）、`ConsumablesView.test.ts`（扫码打开领用、管理员切到入库）。
- 扫码弹出领用后误点提交会直接扣库存：数量默认 1，对话框标题写着耗材名；领错了可以"退回"。
- verify-lab 的 `consumables.md` 已更新。
