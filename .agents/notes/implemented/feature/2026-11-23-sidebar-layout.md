# Agent Note: 侧栏照 Gemini 排：标志在上、账号在下、搜索成图标、可收起

Status: implemented

## Problem

- 用户（2026-11-23）发来 Gemini 侧栏的截图，问"侧边栏按照这样式咋样"，看完方案后说"先做出来吧，本地我看看效果"，看完第二版后说"prci合并主分支，但是不发布版本"。
- 原来的侧栏从上到下是账号按钮、一整行搜索框、菜单。登录后没有任何地方能回到首页（`/login` 对已登录的人直接跳回工作台），用户问过"登陆进去还能返回 home 嘛"。
- 账号和搜索框占了菜单上面两行；侧栏宽度固定 240px，不能收起。

## Decision

- 顶上一行：Phase 标志和名字（链接到首页），右边放大镜图标（打开原来的搜索面板，按 `/` 照旧）和"收起侧栏"按钮。运维账号没有课题组、没有搜索，只有标志和收起按钮。
- 中间是模块菜单，内容不变；菜单比屏幕长时只有这一段滚动。
- 最下面是当前账号（头像、姓名、课题组），点开向上弹出原来的账号菜单。不放齿轮：没有单独的设置页。
- 收起后宽 64px，只剩图标：标志、放大镜、各模块的图标、头像。
  - 第一版收起后是标志、放大镜、展开按钮叠成三行，用户说"不够精简"，要"收起时点击 logo 返回，展开状态点击 logo 才返回 home"。所以收起时标志本身就是"展开侧栏"，悬停换成侧栏图标；展开时的收起按钮也用这个图标（圆角框加一竖，照 Gemini；Element Plus 没有，在 `SideNav.vue` 里画）。
  - 只有一页的模块悬停显示名字；有几页的模块悬停在右边弹出模块名和各页（Element Plus `el-menu` 的 `collapse`）。收起时菜单项的字被隐藏，用 `aria-label` 留住读屏软件念的名字。
  - 未读数、"需处理""有更新"收起时变成图标右上角的小红点（"有更新"是蓝点）。收起状态记在浏览器里（`localStorage` 的 `lab.sidebar.folded`）。
- 首页对已登录的人也能打开：首屏和顶栏的按钮写"进入工作台"（运维写"进入系统管理"），不弹登录框。带 `next` 打开 `/login` 时，已登录的人照旧直接去那一页（路由守卫）。
- 手机：抽屉里同样的顺序（标志和放大镜、菜单、账号），没有收起按钮；底部标签栏不变。
- DESIGN.md"布局"一节照此改写；"侧栏旁边不挂小弹层"加一条例外：收起时悬停的名字和分组弹出，一次只出一个，移开就关。

## Alternatives considered

- **收起后点有几页的模块就把侧栏展开，不弹出**：不违反"不在侧栏旁边挂小弹层"，但每次要多点一下，展开后还要再收。
- **账号旁边放齿轮**：Gemini 有，但我们的个人信息、修改密码都在账号菜单里，齿轮只会打开同一个菜单。
- **只加一个"回首页"链接，不改排法**：能解决回首页，但菜单上面仍压着两行。
- **收起时保留单独的展开按钮**：第一版就是这样，用户嫌不够精简。

## Consequences

- 收起时分组靠悬停弹出，只用键盘的人要先展开侧栏才能进分组里的页面（单项照常能 Tab 到）。收起状态下回首页要先展开。
- 已登录的人按浏览器"后退"回到 `/login` 时，看到的是首页（"进入工作台"），不再自动跳回工作台。
- 验证：
  - 前端测试：`AppMenu.test.ts` 覆盖收起时不自己展开分组、当前模块仍标出、展开后自己点开的组和当前组照旧；`LoginView.test.ts` 覆盖已登录时按钮写"进入工作台 / 进入系统管理"、点了进去不弹登录框；`router.test.ts` 覆盖已登录打开 `/login` 停在首页、带 `next` 时直接去那一页。
  - verify-lab 浏览器（`mgr`、`ops`，1440 宽和 390 宽，截图在 `backend/var/verify-evidence/2026-11-23-sidebar/`）：展开、收起、刷新后保持；悬停"通知"显示"通知 3"和红点，悬停"科研记录"弹出模块名和三页；收起时运维"存储与备份"有红点；账号菜单向上弹出；收起时标志悬停换成侧栏图标、点了展开；展开时点 Phase 到首页、"进入工作台"回工作台，运维"进入系统管理"回存储与备份；600 高的窗口里账号贴底、只有菜单滚动；手机抽屉里是同样的顺序、没有收起按钮。
