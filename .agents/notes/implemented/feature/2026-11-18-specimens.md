# Agent Note: 试样与标准件台账：缺陷参数默认对学生隐藏，借用只登记不预约

Status: implemented

## Problem

开发手册第 1 节把"试样与标准件"列为"先不做"，第 11 节把原型里的"试样与标准件、盲测真值"列为"暂不做"。超声检测课题组天天用试块，至今只有实验记录里一个自由文本的"试件"字段：

- 哪块试块在谁手里、放在哪，只能问人。
- 试块上人工缺陷的参数（平底孔直径、埋深、位置）散落在各人的笔记里。
- 做盲测时，这些参数就是"标准答案"，不能让被测的学生先看到。

2026-11-18 用户同意按建议做：缺陷按条记录；盲测真值对学生隐藏，管理员公开后才可见；借用只做"借出、归还"登记，不做日历预约；实验记录可以选台账试件。

## Decision

- **新模块 `specimens`**（业务层，只引用 projects 及以下；`research` 可以引用它）：
  - `Specimen`：编号（组内唯一）、名称、类别（标准试块、对比试块、试样、其他）、材料、尺寸、存放位置、保管人、状态（可用、损坏、停用）、`defects_public`、备注，有修改历史。不删除，不再用的改为"停用"。
  - `Defect`：类型（平底孔、横通孔、刻槽、裂纹、分层、其他）、尺寸 mm、埋深 mm、位置、备注。随试件一起编辑，整份替换。
  - `SpecimenLoan`：借用人、项目、用途、预计归还日期、借出时间、归还时间、登记归还的人、归还说明。
- **盲测真值的保护**：
  - `defects_public` 为假时，学生拿到的 `defects` 是 `null`。不返回空列表，也不给个数，因为个数本身就泄露了一部分答案。管理员和导师总能看到。
  - 搜索不匹配缺陷字段，避免学生用搜索试探答案。
  - 修改历史只记录 `Specimen` 的字段。改缺陷时写一条原因"修改了缺陷参数"，不写数值。
  - 实验记录里内嵌的试件只有编号、名称、状态。
- **借用**：
  - 任何组员都能借"可用"且没借出的试件，借用人是自己。借用时锁住试件这一行，再检查状态和有没有未归还的借用。
  - 数据库约束保证同一件同时只有一条未归还的借用（`returned_at IS NULL` 上的部分唯一索引），作为最后一道防线。
  - 借用人或管理员登记归还，可以写归还说明。
  - "借出"不是状态，由有没有未归还的借用推算，与设备的"使用中"是同一个思路。
  - 管理员改状态时也锁同一行，所以"标为损坏"和"借出"不会交错。
- 借用归还的批次校验及缺陷必填修复见 [归还批次与缺陷校验](../bug-fix/2026-11-18-specimen-return-and-defect-validation.md)。
- **实验记录**：`Experiment.specimen_items`（多对多，可空），原来的文本字段"试件"保留，用来写台账外的试件。
- **前端**：`src/modules/specimens/`，有列表、详情（缺陷参数、借用记录、借用对话框、登记归还）和新增/编辑对话框（缺陷逐行编辑，"对学生公开"开关）；菜单放在"设备耗材"分组；实验记录页加了 combobox "台账试件"。

## Alternatives considered

- **缺陷参数写成一段文字**：最简单。但没法按尺寸、埋深比较，也没法以后做"按缺陷类型统计检出率"。
- **盲测真值单独存一张表，只给管理员接口**：隔离更彻底。但同一个缺陷就要在两处维护；而且标准试块的参数本来就是公开的，按件开关就够了。
- **借用走预约日历**（像设备那样）：试块借期常常是几天到几周，按时段预约不合适，日历也会被长借用占满。真有排队需求时再做。
- **借出作为一个状态**：要同时维护状态和借用记录，两边容易对不上；由借用记录推算只有一个来源。

## Consequences

- 验证（2026-11-18）：
  - 后端新增 8 个测试，覆盖权限、外组隔离、学生看不到缺陷、搜索不泄露、缺陷整份替换与历史不记数值、借用和归还、只有可用的能借、一条未归还借用的数据库约束、实验记录关联；前端新增 3 个对话框测试和 1 个路由测试。
  - 浏览器按 verify-lab 的 `specimens.md` 走过，证据在 `backend/var/verify-evidence/2026-11-18-specimens/`。
- 走查中发现并修好：详情页的路由写成了 `:id(\d+)`（JS 字符串里 `\d` 就是 `d`）。在页面里点链接能进去，直接打开地址却是"页面不存在"。新增的路由测试检查所有详情地址都能按路径打开，用错误写法验证过它会失败。
- 实验记录列表多了一次预取查询，N+1 测试的上限从 5 改为 6，仍然和行数无关。
- 没做：
  - 工作台"我借的试件""逾期未还"提醒；
  - 逾期邮件；
  - 试件照片、证书附件；
  - 按缺陷统计。

  已写进待办方案，交给后续开发。
- 已知限制：预计归还日期允许填过去的日期；列表的两个筛选 checkbox 没在浏览器里点过，只有接口测试。
