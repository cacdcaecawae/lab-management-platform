# Agent Note: 项目进展可改删与阶段资料、周报撤回附图与汇总秒批、组会记录人（#58 P4）

Status: implemented

## Problem

Issue #58 第二轮走查（项目负责人逐条确认过方向）在项目、周报、组会三处发现这些麻烦：

- 项目：进展日志写错了改不了、删不掉；开题、中期、结题报告没有放的地方；"资产"里没有数据处理；项目列表不能按负责人看；工作台说"组里有 N 个任务已逾期"，点进去是全部项目，要自己一个个找。
- 周报：学生刚提交就发现漏写了，只能等导师退回；本周的曲线、照片只能贴进正文的文字描述里；本周记了哪些实验和处理要一条条去挑；导师在"本周汇总"里看完一份，要点进详情才能给"已阅"。
- 组会：没有时间和地点、会议号；学生轮流记纪要，但只有导师、管理员能编辑；导师不是管理员时，不能勾行动项完成（`ActionItemViewSet.done` 只认负责人和管理员，是遗漏）。

相关决定：[项目汇总与成员写进展](./2026-11-23-project-overview-and-uploads.md)、[项目任务与里程碑](./2026-11-18-project-tasks-milestones.md)、[周报汇总与科研记录效率](./2026-11-23-research-and-reports-efficiency.md)、[组会行动项跨期跟踪](./2026-11-23-meetings-actions-and-report-reminders.md)、[第四期知识库、组会、成果](./2026-11-17-phase4-knowledge-meetings-achievements.md)、[修改历史](../architecture/2026-11-16-change-history.md)。

## Decision

### 项目（`backend/projects/`）

- **进展可改可删**：新路由 `PATCH / DELETE /api/project-logs/{id}/`，记录人、项目负责人、导师、管理员可以改日期和内容或删掉；其他人 403"仅记录人、项目负责人、管理员或导师可以修改或删除进展"，外组 404。新增仍走 `POST /api/projects/{id}/logs/`。进展日志不加修改历史。
- **项目文件 / 阶段资料**：新模型 `ProjectFile`（迁移 `projects/0003`），写法同组会附件：服务器生成存储名（`core.files.stored_name`），`checked_upload` 校验，`download` 下载（PDF、图片在页面里打开，其他类型一律下载）。`GET / POST /api/projects/{id}/files/`：本组全员可看，项目现任成员、负责人、导师、管理员上传（非成员 403"仅本项目成员、管理员或导师可以上传文件"）；`GET /api/project-files/{id}/file/` 下载；`DELETE /api/project-files/{id}/` 上传人、负责人、导师、管理员，存储里的文件在事务提交后删。项目没有删除接口，所以上传不像组会那样锁父记录。项目详情加一张"项目文件"卡片，用共用的 `AttachmentList`（缩略图、在线预览）。
- **资产**：`ProjectAssets.vue` 的"实验记录"改名"实验与原始数据"，"数据集"一块换成"数据处理"（`/api/runs/?project=`）。"成果归档"一块要等成果能关联项目（P6-3 加 `Achievement.project`）再接，代码里留了 `shortcut:` 注释。
- **列表筛选和逾期标记**：`Project` 多一个只读的 `overdue_tasks`，是未完成、截止日期早于今天的任务数，口径和工作台的逾期任务数一样（`Count(..., distinct=True)`，因为 `?mine=1` 会连上成员表）。列表加 `?leader=<编号>`（不是数字时返回空）和 `?overdue=1`；页面加"负责人"下拉、"有逾期任务"筛选胶囊，状态一栏标"N 个任务逾期"。加了聚合以后 Django 不再套用 `Meta.ordering`，所以显式按 `-updated_at, -id` 排。
- **工作台直达**：工作台"组里有 N 个任务已逾期"改为打开 `/projects?overdue=1`（`WorkbenchView.vue` 只改了这一行）。从这个链接进来、结果只有一个项目时，直接换到它的任务看板（`?tab=tasks`），并关掉列表这一页的顶栏标签（标签记着 `?overdue=1`，切回去会再跳一次）；在页面上自己勾"有逾期任务"不跳。

### 周报（`backend/reports/`）

- **撤回修改**：`POST /api/reports/{id}/withdraw/`，只有本人、只在 `submitted`（导师还没批阅）时可以撤回，其他状态 409 `invalid_state`。撤回让周报回到提交之前的状态：第一次提交的回到 `draft`，清空 `submitted_at`；被要求补充后重新提交的回到 `needs_revision`，导师的反馈留着，仍算已交。两种都清空 `data_versions`，下次提交重新固定数据版本；修改历史里记"本人撤回修改"。页面按钮"撤回修改"先确认。
- **附图与附件**：新模型 `ReportFile`（迁移 `reports/0004`），可见范围同周报（`scope_private`，经 `report__owner`）。`POST /api/reports/{id}/files/` 本人在草稿、需补充时上传，其他状态 409（文件先写，锁住周报确认状态后再落库，失败就删掉刚写的文件）；`DELETE /api/report-files/{id}/` 同样只在可编辑时；删除草稿周报时连同附件文件一起删（锁住周报之后再读附件列表，刚传完的那个也算上）。`WeeklyReport` 返回 `files`，所以周报详情和导师的"本周汇总"卡片都能直接看图。
- **一键带入本周记录**：`GET /api/reports/week-records/?week_start=` 返回本人在这一周（周一到周日，按北京时间的日期）新建或提交的实验与原始数据、数据处理（`ExperimentBrief` / `RunBrief`）。按钮把它们加进两个关联下拉，已选的不重复。查询放在 `reports` 里（分层表允许 `reports → research`），不改实验和处理记录的列表接口。
- **只关联实验与原始数据、数据处理**：编辑页去掉"关联数据集"下拉；旧周报已关联的数据集只读列出，`dataset_ids` 原样回传，提交时照旧固定版本。关联下拉都带 `owner=<本人>`：P1 之后实验、处理列表还会列出同项目队友已提交的记录，周报只能关联自己的（后端 `OwnRecordField` 本来就拒绝别人的编号）。
- **汇总页秒批**：本周汇总里每张"已提交"的卡片右上角有"写评语"和"一键已阅"。"一键已阅"直接发"已阅"；"写评语"展开一个输入框，可以写评语后点"已阅"，或写明要补充什么后点"需补充"（不写内容不发请求）。走原来的 `POST /api/reports/{id}/feedback/`，返回的周报替换这张卡片。

### 组会（`backend/meetings/`）

- **时间、地点、记录人**：`Meeting` 加 `time`（可空，接口里是 `HH:MM`）、`location`（"地点 / 会议号"）、`recorder`（本组成员，`AnyGroupMemberField`，已离组的也保留）。迁移 `meetings/0004` 同时改历史表；修改历史抽屉给这三个字段起了中文名。
- **记录人写纪要和行动项**：`PATCH /api/meetings/{id}/` 对导师、管理员不变；不是导师或管理员时，只有本场记录人可以改，而且请求里只能有 `minutes`、`actions`（`RECORDER_FIELDS`），带别的字段 403"记录人只能编辑纪要和行动项"；其他人 403"仅导师、管理员或本场记录人可以编辑组会"，外组 404。改行动项时的带入、删除、通知规则和导师编辑时一样。页面上记录人看到"记录纪要"，编辑时只有纪要和行动项两块。
- **导师勾行动项**：`ActionItemViewSet.done` 从"负责人或管理员"改为"负责人或导师、管理员"（`is_supervisor`）。组会详情和"行动项"标签的复选框跟着放开。

### 权限一览（`docs/architecture.md` 的表同步改了）

| 记录 | 读 | 写 |
|---|---|---|
| 项目进展 | 本组全员 | 新增：项目成员、负责人、导师、管理员；改删：记录人、负责人、导师、管理员 |
| 项目文件 | 本组全员 | 上传：项目成员、负责人、导师、管理员；删除：上传人、负责人、导师、管理员 |
| 周报附件 | 本人、本组导师 | 本人，周报为草稿或需补充时 |
| 周报撤回 | — | 本人，周报为已提交时 |
| 组会 | 本组全员 | 新建、编辑：导师、管理员；本场记录人：纪要和行动项；删除：管理员 |
| 行动项完成 | 本组全员 | 负责人、导师、管理员 |

## Alternatives considered

- **撤回一律回到草稿（issue 原话"退回草稿"）**：最直白；但草稿可以删除，导师给过的"需补充"反馈会随周报级联删掉，学生也会从已交名单里消失。按"回到提交之前"处理：第一次提交的就是草稿，和原话一致；补充后再交的回到"需补充"，反馈和已交状态都还在。
- **周报附件、项目文件存成数据集**：上传、SHA256、权限都现成；但数据集是科研数据，有版本固定和"不可删除"的规矩，P1 还在改它的结构；周报里的截图和项目的开题报告不是原始数据，按组会附件那样的小文件表更合适。
- **项目阶段资料放进知识库**：知识库有版本和全组检索；但阶段资料属于某个项目，放进全组文库还要再加"所属项目"和对应的权限，项目成员上传也不符合知识库"只有管理员能删"的规矩。
- **一键带入由前端调实验、处理列表筛日期**：不用新接口；但两个列表没有按创建或提交日期筛的参数，要加就得改 P1 正在改的 `research` 视图。放在 `reports` 里一次取回，和 P1 互不干扰。
- **逾期任务数用子查询**：不会和成员表的连接相乘，也不会让 `Meta.ordering` 失效；但写法更长。用 `Count(distinct=True)` 加显式排序，测试里覆盖了 `?mine=1` 不会翻倍。
- **进展日志加修改历史（`HistoricalRecords`）**：负责人改了别人的进展也能追溯；但[修改历史](../architecture/2026-11-16-change-history.md)只给有提交、审阅流程的记录，进展日志一直没有；issue 也没要求。代价写在后果里。
- **记录人可以改组会所有字段**：少一层判断；但日期、议程、记录人本身由主持组会的导师定，记录人只负责记录。

## Consequences

- **收益**：进展写错能改；阶段资料跟着项目走，组里都能在线看；工作台的逾期任务一点就到对应看板；学生提交后发现漏写可以自己撤回；导师在一页里批完本周周报；记纪要不再必须找导师或管理员。
- **代价与已知上限**：
  - 负责人、导师、管理员改或删别人的进展不留记录，"记录人"仍显示原作者。组里在意时给 `ProjectLog` 加 `HistoricalRecords`。
  - `ProjectFile`、`ReportFile` 没有算进存储用量（`workbench/storage.py` 不属于 P4），要另开一项补上。
  - 撤回后，导师先前收到的"有新的周报待反馈"通知还在，点开看到的是草稿。
  - 记录人不能上传组会附件，被指定为记录人时也没有通知。
  - 资产页的"成果归档"等 P6-3。
- 测试：`projects/tests/test_logs_files_overdue.py`（改删进展的四种身份和 403/404、项目文件上传下载删除和存储清理、逾期计数、`?mine=1` 不翻倍、`?leader=`、`?overdue=1`），`reports/tests/test_withdraw_files_week.py`（撤回的状态和版本、补充后撤回回到需补充且不能删、附件的读写范围和状态、删草稿清文件、按北京时间的周界），`meetings/tests/test_recorder_and_done.py`（时间地点记录人、记录人只能改纪要和行动项、导师勾完成）。前端：`ProjectsView.test.ts`（工作台直达只有一个时跳看板）、`ReportEditView.test.ts`（一键带入不重复、撤回）、`ReportsView.test.ts`（一键已阅、需补充要写内容）、`MeetingDetailView.test.ts`（记录人只发 `minutes`、`actions`）。
- 验证：`DB_TEST_NAME=test_lab_p4 bash scripts/check.sh` 全部通过：笔记校验 87 篇，`makemigrations --check` 无变化，后端 597 passed、1 skipped，前端 58 个测试文件、216 个测试，`vue-tsc` 和构建通过。
  - 浏览器（verify-lab 隔离实例，2026-11-25，本分支代码）：项目成员上传项目文件，在线预览 PDF，存储文件与原文件 SHA256 一致；记录人改进展，负责人删别人的进展；资产五块；工作台逾期直达唯一逾期项目的任务看板，不留列表标签；列表的逾期标签和负责人筛选。一键带入本周记录，再点不重复；附图缩略图；第一次提交后撤回回到草稿，补充后再交的撤回回到需补充、反馈保留；本周汇总里看图，写评语后点需补充，一键已阅。组会的时间、地点和记录人；记录人只改纪要和行动项（改标题、勾别人的行动项都是 403）；不是记录人的汇报人 403；没有管理员标签的导师勾行动项完成。外组读新接口一律 404。截图和数据库核对在 `backend/var/verify-evidence/2026-11-25-p4-{projects,reports,meetings}/`（不提交）。
