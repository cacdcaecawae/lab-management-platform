# Agent Note: 项目详情汇总关联的科研资产，成员也能写进展，数据集拖拽上传（issue #48 N5 余下）

Status: implemented

## Problem

- N5 的数据集部分已由 PR #52 完成：引用来源、打包下载、复制为草稿、删草稿、编辑和删除空数据集。还差三件。
- 实验记录、数据集、设备预约、试件借用、耗材领用都能关联项目，但项目详情页只有基本信息、进展、任务、里程碑。想知道"这个项目做了哪些实验、用了哪些设备和耗材"，只能到各模块一个个筛。
- 进展日志只有项目负责人和导师、管理员能写，项目里的其他成员不能写，进展就只剩负责人一个人的视角。
- 数据集上传只能点按钮选文件，不能把文件直接拖进来。
- 相关决定：[周报汇总与科研记录效率](./2026-11-23-research-and-reports-efficiency.md)（N5 已做的部分）、[模块边界](../architecture/2026-11-17-module-boundaries.md)。

## Decision

- **项目汇总**：项目详情加"资产"标签，五块：实验记录、数据集、设备预约、试件借用、耗材出入库（[#58 P4](./2026-11-25-projects-reports-meetings-polish.md) 起前两块是"实验与原始数据""数据处理"）。每块列最近 10 条和总数，"全部 N 条"打开那个模块的列表并带上 `?project=`。
  - `projects` 不能依赖业务模块，所以不做后端汇总接口：各模块的列表接口按 `?project=` 筛，页面（`ProjectAssets.vue`）按"页面可以调用别的模块 `api`"的规则分别去取。每块独立加载、独立显示失败。
  - 补的接口：预约列表 `/api/bookings/all/` 加 `project`；新的 `GET /api/specimen-loans/`（全组的借用，`project`、`specimen`、`open=1`，带试件编号和名称，不带缺陷参数）；耗材出入库用 N7 的总账 `/api/stock-txns/`。实验记录、数据集原来就有 `project`。
  - 数据范围照旧：实验记录、数据集是个人数据，学生在这里只看到自己的；预约、借用组内公开；耗材流水按 N7 的规则（导师、管理员看全组，其他人看自己经手的）。
  - 列表页从地址读 `project`（实验、处理记录、数据集、预约列表、耗材流水）。试件借用没有全组的列表页，那一块只显示总数。
- **成员写进展**：新增进展日志从"负责人、导师、管理员"放宽到"项目现任成员、负责人、导师、管理员"；不在项目里的学生 403"仅本项目成员、管理员或导师可以写进展"。修改、删除进展后来由 [#58 P4](./2026-11-25-projects-reports-meetings-polish.md) 加上：记录人、项目负责人、导师、管理员。
- **拖拽上传**：数据集详情的"文件"卡片接受拖进来的文件（一次多个），走和"上传文件"按钮同一个上传函数（进度、同名拒绝、SHA256、磁盘空间）。拖着时卡片显示虚线框和"松开上传"；拖文件夹时提示不支持。

## Alternatives considered

- **在 `workbench` 里做一个项目汇总接口**：`workbench` 可以依赖所有业务模块，一次请求拿全；但项目页的数据范围规则要在汇总接口里再写一遍，容易和各模块列表不一致。用各模块自己的列表接口，范围规则只有一份。
- **所有成员都能改、删任何人的进展**：最自由；但进展是谁写的要算数，改别人的记录会让历史不可信。
- **拖拽上传用第三方上传组件**：功能多；但现有的上传函数已经处理了进度、校验和磁盘空间，只缺拖放事件。
- **试件借用另做一个全组借用列表页**：能有"全部 N 条"的链接；但只为这一处多一页，项目里通常没几条，显示总数就够。

## Consequences

- 测试：`projects/tests/test_assets_and_logs.py`（成员能写进展、非成员 403；各列表按项目筛、学生只看到自己的实验、外组看不到）。前端 `SpecimenDetailView.test.ts` 的借用数据加了试件。
- 项目页一次发五个请求，网络差时会慢一点；各块独立显示失败，与 B8 / U3 的"副接口失败不白屏"一致。
- 借用接口多了 `specimen` 字段（单个试件的借用列表也有），只是编号和名称。
- verify-lab 的 `project-tasks.md`、`datasets.md` 已更新；拖放在 chrome-devtools 里要用脚本派发 `drop` 事件代替。
