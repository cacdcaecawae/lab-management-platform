# Agent Note: 成果统计：按年份、类型、成员汇总

Status: implemented

## Problem

写年度总结时，需要看论文、授权专利、获奖及软著的分组成果，按成员和年份人工数清单容易重复计算。原提议以「已录用、已发表」作为默认状态，只对论文成立，会漏掉其他类型。

## Decision

- 成果归档新增「成果统计」；本组全员可查看。默认正式成果按类型分别取已录用及已发表论文、已授权专利、已获奖、已登记软著。列表、原清单导出与统计共用 `status=formal` 的定义；显式状态过滤保持原语义。
- 年份取登记成果日期；该字段必须填写，不增加虚假的「未填年份」行或数据库迁移。可单侧限定年份，两端均含；年份表不填充空年份。
- 组总计与年份表每项成果只计一次，按明确关联的当前本组成员各计 1 项，原样作者文本不拆解。无本组作者的成果仍进入组总计；成员合计不可直接相加得组总计。
- Excel 专用路径，使用与 JSON 相同的分组汇总、选项和去重总计；按年和按成员两页，不读取全文或新依赖；所有用户内容以数据写入。

## Alternatives considered

- 所有类型共用已录用/已发表过滤：授权专利、获奖和登记软著会被系统性丢掉。
- 只导出而不显示统计：即时核对费力。
- 从自由文本作者名字猜测所属成员：姓名重合、别名和外部作者导致错误归属。

## Consequences

- PostgreSQL 合成用例覆盖正式状态、年份、按人统计与去重、外组隔离、无本组作者、Excel 单元格与 JSON 及无效过滤。Vue 组件覆盖默认值和导出过滤；真实浏览器结果单独记录。
