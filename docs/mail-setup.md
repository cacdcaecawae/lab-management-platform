# 学校邮箱怎么配

平台只需要一个能发信的邮箱账号。建议用课题组的公共邮箱，或者专门申请一个"平台通知"账号，不要用某个人的私人邮箱：人毕业或换邮箱后，通知就断了。

设置在网页里完成，不用改服务器上的文件，也不用重启：运维账号登录 → "系统管理" → "邮件"。

## 1. 在学校邮箱里打开 SMTP，拿到授权码

1. 用这个账号登录学校的网页邮箱，打开"设置"。这一项各家叫法不同，常见的有"客户端设置""POP3/SMTP/IMAP""账户安全""客户端授权码""客户端专用密码"。
2. 打开 SMTP 发信服务，生成一个"客户端授权码"。平台里填的是这个授权码，不是网页邮箱的登录密码。
3. 同一页通常写着 SMTP 服务器地址、端口和是否使用 SSL，照抄下来。页面上找不到的话，问学校网络中心（信息化处）三件事：
   - SMTP 发信服务器的地址；
   - 端口，以及要不要 SSL / STARTTLS；
   - 有没有限制：是否只允许校内网络使用，是否允许发往校外邮箱，每天能发多少封。

## 2. 填进平台

| 项 | 填什么 |
|---|---|
| SMTP 服务器 | 学校给的域名，例如 `smtp.xxx.edu.cn`。填域名，不要填 IP 地址，否则证书校验会失败 |
| 端口、加密方式 | 按学校给的填。没说的话先试 465 + SSL，不行再试 587 + STARTTLS。换加密方式时端口会跟着换成常用值；手动改过端口后就不再跟着换 |
| 账号 | 完整的邮箱地址 |
| 授权码 | 第 1 步生成的授权码。保存后页面只显示"已设置"，以后留空就是不修改 |
| 发件人地址 | 一般留空，平台会用账号作发件人。大多数邮箱要求发件人和登录账号相同 |

然后：

1. 点"保存"。
2. "收件地址"填你自己的邮箱，点"发送测试邮件"。邮件还没启用时也可以发，先试通再打开。
3. 收到测试邮件后，打开"启用邮件"，再点"保存"。从这以后，设备异常、采购审批、到货、财务提醒都会发邮件。

## 3. 发不出去时

页面会弹出服务器给的原因，后面跟着要检查什么；"最近一次发送失败"的红框里也会留着，下次发送成功后自动消失。常见情况：

| 提示 | 一般是什么问题 | 怎么办 |
|---|---|---|
| `535`，"账号或授权码不对" | 填的是登录密码，或者没开 SMTP 服务 | 回第 1 步开启 SMTP、生成授权码，重新填 |
| `530`，"服务器要求先加密或先登录" | 选了"不加密"，或者没填账号 | 加密方式改为 SSL 或 STARTTLS，填上账号和授权码 |
| "服务器在这里不提供登录" | 多数邮箱要先加密才允许登录 | 改为 SSL 或 STARTTLS |
| `553` / `550`，"服务器不接受这个发件人" | 发件人地址和账号不一致 | 把"发件人地址"清空 |
| "收件地址被拒" | 收件地址写错，或者学校邮箱不允许发往校外 | 先发给一个校内地址试试 |
| `WRONG_VERSION_NUMBER` 或 `Connection unexpectedly closed`，"加密方式和端口对不上" | 465 端口选了 STARTTLS，或者 587 端口选了 SSL | 465 选 SSL，587 选 STARTTLS |
| "证书上的域名和填写的服务器地址不一致" | 填了 IP 或别名 | 改填学校公布的 SMTP 域名 |
| "服务器证书不受信任" | 学校服务器的证书是自签名的，或者证书链不完整 | 确认地址无误后，请网络中心处理 |
| "找不到这个服务器" | 地址拼错，或者这台机器上不了外网 | 检查拼写；在服务器上能不能访问外网 |
| "连接超时" | 端口被防火墙挡住，常见是云服务器封了 25 端口；或者学校 SMTP 只对校内开放 | 换 465；服务器在校外时问网络中心能否开放 |

## 4. 本机试用和部署到服务器

- 本机试用（见 README"本机试用"）先用自带的本机收件箱把通知流程走通；学校账号到了以后，在本机平台里改成学校的 SMTP，发一封测试邮件。本机能发，说明账号、授权码、端口都对。
- 部署到服务器后，在服务器上的平台里再发一次测试邮件。本机能发、服务器不能发，问题多半在服务器的网络：云服务器通常封 25 端口；学校 SMTP 可能不对校外地址开放。

## 安全

- 授权码存在数据库里，页面和接口都不会返回，修改历史里只记"修改了授权码"。数据库备份里也带着它，备份文件要妥善保管。
- 授权码泄露时，在学校邮箱里作废、重新生成，再在平台里填新的。
- 授权码只在平台的网页里填，不要发到聊天记录或写进文件。
- 加密方式选"不加密"时，授权码会以明文经过网络；正式使用请选 SSL 或 STARTTLS。
